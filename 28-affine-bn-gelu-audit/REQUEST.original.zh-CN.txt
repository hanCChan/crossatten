# **S27-B 之后：HStem 下一步应该研究什么机制？**

我已经核对了你最新提交 [`48faa0e`](https://github.com/hanCChan/crossatten/tree/48faa0ec3a878ac096cb26b71c984f2c7ef46a56/27b-tokenizer-backend-interaction?utm_source=chatgpt.com)，包括科研报告、四组训练结果、特征几何、预注册的 S27-C，以及 S22–S27-A 的历史证据。

**我的判断是：S27-B 虽然没有证明 MHA 的协同放大作用，但它反而帮助你进一步定位了 HStem 的核心研究问题。**

现在最值得回答的不是“为什么 Transformer 注意力有效”，而是：

> **为什么多阶段局部卷积的参数化与训练过程，能够在相近的参数预算下，学到比单次大核 Patch 投影更有判别力的射频特征？这种优势是整体分类能力增强，还是专门提高了跨接收机泛化？**

这实际上是两个不同的机制问题，必须用不同实验回答。

## **一、先弄清楚 S27-B 究竟说明了什么**

两种 Tokenizer × 两种后端

| Tokenizer              | MHA           | TokenMLP      | HStem 相对优势 |
| ---------------------- | ------------- | ------------- | ---------- |
| HStem                  | **97.335%**   | **96.448%**   | —          |
| Long-Patch             | 94.500%       | 93.402%       | —          |
| **HStem − Long-Patch** | **+2.835 pp** | **+3.047 pp** | 两种后端均领先    |

各后端下 HStem 相对 Long-Patch 的准确率优势

0 pp0.8 pp1.6 pp2.4 pp3.2 ppMHATokenMLP

主交互：

\\[ \Delta\_{\mathrm{int}}=2.835-3.047=-0.212\ \mathrm{pp} \\]

条件 95% 区间为 [−0.845, 0.600] pp，没有达到预注册的正交互门槛。

因此可以认为：

- **已得到支持：** 在这两个预先固定的后端中，HStem 相对 Long-Patch 的优势都能保持。
- **没有得到支持：** MHA 会额外放大 HStem 的相对优势。
- **仍然不知道：** HStem 究竟通过哪些内部参数化和训练机制获得这种优势。

还有一个非常重要的反例：TokenMLP 后端的最终源域特征分离比，HStem 为 **6.844**，高于 MHA 的 **5.449**，但 Dev 准确率反而低了 0.887 pp。

说明**不能简单用“最终特征分离比越高，所以模型跨接收机越强”作为论文的机制解释**。

这要求下一阶段从特征相关性分析，进一步转向真正的**结构干预实验和训练机制检验**。

## **二、下一阶段，我建议重点拆解“分层参数化为什么有效”**

现在已有的证据可以归纳为：

| 已完成实验          | 排除了什么解释            | 尚未解决什么             |
| -------------- | ------------------ | ------------------ |
| S26 Long-Patch | 不是单纯增大局部支持范围       | 深层分解、BN、非线性仍混杂     |
| S27-A No-GELU  | GELU 有贡献，但不能解释全部收益 | 剩余 2.083 pp 从哪里来   |
| S27-B TokenMLP | 未证明优势依赖特定 MHA 协同   | Tokenizer 自身为什么更有效 |
| S22 NoMidBN    | 中间 BN 影响训练结果       | BN 与非线性、分层结构如何共同作用 |

**最值得验证的候选机制是：多阶段卷积分解带来的结构化参数化和训练归纳偏置。**

为什么提出这个假设？

因为 No-GELU 虽然去掉了中间激活函数，但仍然保留了 96.583% 的准确率。它在推理阶段的中间 BN 使用固定统计量，所以整个 Tokenizer 相对于共享前端输入是一个仿射映射。

这意味着：

**No-GELU 与 Long-Patch 都不需要依靠 Tokenizer 内部的输入相关非线性完成计算，但它们的准确率仍相差 2.083 pp。**

因此，值得研究的已经不是非线性是否有用，而是：

> 即使最终能表示为线性或仿射算子，为什么经过多层卷积分解与 BN 训练获得的权重，可能比直接优化一个大核更有效？

这会比“多尺度特征提取效果更好”具有更明确的数学研究对象。

## **三、建议新增 S28-A：BN × GELU 因子实验**

你现有历史模型实际上已经具备一个 \\(2\times2\\) 因子实验中的三组。

|             | 保留 GELU             | 去掉 GELU             |
| ----------- | ------------------- | ------------------- |
| **保留中间 BN** | HStem **97.335%**   | No-GELU **96.583%** |
| **去掉中间 BN** | NoMidBN **96.145%** | **待训练**             |

只需要新增一种模型：

**HStem-NoBN-NoGELU**：四层卷积的核、通道、步长、MHA 和训练配方全部不变，仅将 Tokenizer 中三个中间 BN 和三个 GELU 都替换为 Identity。

建议新增两折 × 三种子，**六次拟合**，不重新训练历史三个模型。

其核心指标不是新模型本身的准确率，而是交互：

\\[ \Delta\_{\mathrm{BN}\times\mathrm{GELU}} = (A\_{\mathrm{BN,GELU}}-A\_{\mathrm{BN,noGELU}}) - (A\_{\mathrm{noBN,GELU}}-A\_{\mathrm{noBN,noGELU}}) \\]

它能够检验：**GELU 的收益是否受到 BN 存在与否的影响。**

更重要的是，新模型可以与 Long-Patch 进行分析性对照。

| 可能结果                         | 科研解释                   |
| ---------------------------- | ---------------------- |
| NoBN-NoGELU 仍明显优于 Long-Patch | 支持分层卷积参数化本身具有候选优势      |
| NoBN-NoGELU 接近 Long-Patch    | BN 与非线性可能解释较多现有收益      |
| NoBN-NoGELU 明显更弱             | 分层结构并不是无条件有效，其训练依赖值得分析 |

这些都只能作为机制线索。因为新模型与 Long-Patch 的优化参数空间、初始化和算力仍不完全一致，不能从准确率差异直接推出“分层参数化是唯一原因”。

此外，该实验是在观察 S27 结果后提出的，应明确登记为**新增探索性机制实验**，不能冒充此前已封存的独立假设验证。

### **同时做一项零训练的数学审计**

对于冻结的 No-GELU 网络，可以写成：

\\[ T(x)=W_4B_3W_3B_2W_2B_1W_1x+b \\]

其中 \\(B_i\\) 表示推理阶段已经冻结的 BN 仿射变换。

在适当的算子表示下：

\\[ T(x)=W\_{\mathrm{eff}}x+b\_{\mathrm{eff}} \\]

下一步可以尝试将这一多层映射物化为一个等价算子，并检查原 Tokenizer 输出与物化输出的数值误差。

但必须考虑多级 stride、padding 与边界位置：**整体仿射并不保证可以直接用一个普通共享卷积核在所有边界位置精确替代。** 应先通过源域样本验证等价性；若边界不等价，就显式处理边界，而不是只截取有利位置。

这项实验可以建立一个非常有意义的区分：

**推理时的函数表示形式，与训练时采用的参数化路径，不是一回事。**

如果能够证明 No-GELU 的最终映射可等价物化，而它在原训练协议下仍优于直接 Long-Patch，这就加强了研究训练参数化的动机。不过，严格证明优化归因还需要后续控制训练，物化本身不能单独证明。

## **五、真正有望形成论文核心机制的下一步是什么？**

如果 S28-A 发现分层参数化确实有稳定优势，就应该进一步从训练动力学解释它。

我建议优先考虑**同一起始函数、不同参数化优化路径**的控制，而不是继续随机加入模块。

例如对 NoBN-NoGELU 或 No-GELU 进行等价算子审计后，比较：

**同一个初始化的有效映射**

**分解参数训练**

多阶段卷积参数，梯度分别更新

**有效算子直接训练**

将等价映射作为直接可学习参数

**比较相同初始预测下的训练收敛、核谱和跨 RX 表现**

这项实验比简单的 HStem/Long-Patch 比较更接近参数化机制，但要承认直接算子通常会改变自由参数量、约束和优化器状态，因此需要特别设计匹配条件，不能未经审计就称作严格因果实验。

重点分析有效卷积核的奇异值、频率响应、有效秩，以及训练过程中这些量的演化。你已有的 S23 核谱结果可以用于提出假设，但不能将前端核谱直接解释为真实发射机的硬件频谱。

如果最终观察到分层训练更稳定地形成有利于 TX 分类的受约束滤波器，并且与直接参数化训练存在可重复差异，就可能形成一项比“多级 CNN 有效果”更扎实的训练机制研究。

## **最终科研判断**

**当前最值得深入的创新方向，是“多阶段局部卷积的结构化参数化如何影响射频身份特征学习”，而不是“MHA 与 CNN 协同”或“逐层去除接收机信息”。**

经过 S27-B，你实际上已经知道：HStem 的优势不只依赖特定后端；GELU 只能解释其中一部分；源域最终特征几何也不能充分预测跨 RX 准确率。

接下来需要用 **BN×GELU 因子干预、等价算子与训练动力学分析**，解释结构为什么有效；再通过 **S27-C 的真正留出源接收机实验**，判断这种结构效果是否具有跨 RX 专属性。

如果第一条成立、第二条不成立，你仍然可以写成有实验支持的**参数高效层级 RF 特征学习方法**，但不能宣称发现了新的接收机不变性机制。

如果两条都成立，并且以后能在独立物理接收机上得到支持，才更有基础将论文贡献提升为**针对跨接收机身份判别设计的结构化学习机制**。
