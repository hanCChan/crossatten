# S17B：相位机制的补充受控干预

本补充在用户继续接收机失真研究的授权范围内，承接S17 D0观察到的相位代理3/4fold复现及错误关联中位数0.256。原S17只允许幅频/IQ自动训练，其STOP及全部阈值不改写。S17B是读取D0后的新问题，以下门槛先于任何相位合成干预结果提交；不是将本轮结果追认成原始预注册结论。

Windows原环境已由用户处理系统设置后恢复：Python3.12.8、torch2.5.0+cu124、4060 GPU合成前反向通过。原阻断记录保留，WSL未安装。继续使用原依赖版本。

## 工程假设修正

S09 first-order相位特征**追加**在FFT Re/Im/LogMag之后，原始实虚部仍然保留。一阶附加通道的理想全局相位不变性不意味着全模型logits不变。原S17整体相位不变性测试失败的记录保留，本补充用正确通道范围的测试验收，不修改历史模型来获得不变性。

## D1固定设计

先训练4个新的端到端HStem+普通MHA基线：ManyRx四fold、first源留出组、初始化seed18101、source split16001。输入[B,2,256]，token[B,32,64]，模型82,426参数。沿用冻结S17小模型循环：FP32、Adam1e-3、batch128、最多40轮、source RX等权CE选模、plateau/earlywait10；这些基线复用为后续M0。

干预只在fit RX验证30%上执行，日期1–2，不打开留出源RX：

- 物理候选W：两个低阶平滑相位基系数独立均匀采样，系数界0.15rad×强度；强度固定0.25/0.5/1，各两个确定draw。
- 同S17的17tap复FIR、FFT512零填充线性卷积、移除已知8点群延迟；相对单位冲激L1距离≤0.25，故全频幅度位于[0.75,1.25]。
- 有限FIR存在残余幅度纹波，不宣称严格all-pass；以频域实际最大纹波的包间95%分位数≤0.25dB约束。
- N：与每个W样本EVM严格相同的proper复高斯噪声。
- G：与每个W样本EVM严格相同的正/负全局相位旋转，角度为±2asin(EVM/2)。G测量简单全局相位效应，不预设模型对其不变。

所有扰动均与TX标签独立，不估计目标RX参数，不拟合补偿网络。

## 非任意扰动：源RX相位代理覆盖检查

使用冻结S17 D0训练RX的32维相位曲率profile：按特征std标准化（floor1e-4），取固定前三个PCA方向。该空间代表RX相关的观测差异，仍混有信道、CFO、噪声，不是唯一硬件相位模型。

源验证清洁/干预样本使用**同一清洁幅度有效支持mask**计算相位曲率，避免阈值支持切换被误算成相位变化。覆盖=干预变化投影RMS/源RX profile投影RMS；对齐率=变化投影能量/总变化能量。

某个强度准入必须同时满足：

1. 每个fold双draw平均：Accuracy/F1下降≤1pp、最差TX下降≤5pp。
2. 每个fold：平均EVM≥0.002、EVM q95≤0.10、实际幅频纹波q95≤0.25dB。
3. 至少3/4fold同时满足：相位子空间覆盖≥0.10、对齐率≥0.15、对齐率比同EVM噪声高至少0.02。

从三个固定强度中取最大准入值；若没有值通过即STOP_D1_GATE。不扩大基函数、强度、seed或模型预算。不把冻结分类器的保持代理当作物理TX信息完全未变的证明。

这些是本轮预先固定的探索出口，并非领域标准：1pp保持容差与后续至少1pp泛化增益的量级一致；0.25dB纹波限制幅度混杂；10%EVM上限约为−20dB扰动功率；10%覆盖要求避免近乎不改变RX代理的无效干预。rank3/32的均匀方向对齐比例约9.4%，15%及比实际同EVM噪声高0.02用于要求额外方向性。它们不能替代独立确认或物理参数可识别性证明。

## 条件Pilot及确认

D1通过后，M0/W/N/G四臂配对，四fold共16 fit（含已训练4个基线）。所有臂初始化和数据顺序一致，训练扰动概率0.5；W/N/G使用相同物理样本随机流、独立辅助随机流。只修改输入，参数与优化器相同，sourceCE选模，不按留出RX选轮数。全部checkpoint先提交seal，再统一评估留出源RX。

W须相对M0、N、G全部满足：ManyRx平均≥+1pp、≥3/4fold为正、最差配对RX≥−2pp、5000次RX整簇条件bootstrap的95%下界>0。条件区间无全流程多重比较校正。控制臂不能晋升新候选。

通过后才依次confirm1(seed18111)、confirm2(seed18112)：last源留出组，ManyRx及ManySig各四fold，四臂全部重新训练。强度及物理配方固定，不重新筛选。每轮32 fit，需分别通过ManyRx门槛，且ManySig平均≥0、≥3/4fold不低于−1pp、最差配对RX≥−2pp。任一轮失败停止。最多80个小模型fit；不自动打开真实目标RX/date3–4或Shen blind。

入口s17b_execute.py；状态STATUS.json；D1_RESULTS.zh-CN.md记录全部强度及失败门槛，后续各阶段CSV和决定保留正负结果。无科学失败自动重试。
