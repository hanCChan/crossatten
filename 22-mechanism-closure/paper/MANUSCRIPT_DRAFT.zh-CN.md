# 严格带内 LoRa 跨接收机识别中的轻量 RF token 形成：方法与实验初稿

本文研究严格零样本跨接收机、闭集10发射机识别，目标是用较少参数保留未见接收机上的身份判别能力。当前证据范围限定在 Shen LoRa 协议，不主张跨 LoRa/WiFi 的通用优势，也不将既有开发接收机上的后续消融视为独立盲测。

输入为8192点复数IQ。使用既有 RMS 标准化和 TrueIB 投影，从带内信号构造 IQ、FFT 与幅相视图，再经 k7/k5 的32通道局部前端形成特征。HStem 使用四阶段卷积，其前三阶段为 k8/s4/p2 的48、64、64通道卷积，分别接 BN 与 GELU，最后用 k4/s4 卷积得到32个64维 token。位置处理、Pre-LN 和分类头遵循既有实现，主机制研究统一采用两层普通 MHA。当前不把 HSTU 当作已证明必要的创新。

卷积构造 token 已有先例：[CvT（ICCV2021）](https://openaccess.thecvf.com/content/ICCV2021/html/Wu_CvT_Introducing_Convolutions_to_Vision_Transformers_ICCV_2021_paper.html) 将卷积引入视觉 Transformer；[Conformer（Interspeech2020）](https://doi.org/10.21437/Interspeech.2020-3015) 结合局部卷积与全局注意力。本文借鉴其局部与全局分工，但这些工作不构成当前 RF 机制的证明，不能据此声称卷积 token 化为首创。[Zhang（ICML2019）](https://proceedings.mlr.press/v97/zhang19a.html) 讨论下采样与平移稳定性，提供未来信号诊断背景；当前尚无依据将 HStem 宣称为已学习抗混叠或满足散射网络稳定性定理。

既有 S15 参数匹配结果中，HStem+MHA 为133690参数，Patch-Lite+MHA为134266参数，开发 RX 等权准确率分别97.335%和94.648%，差值+2.687pp，6/6配对为正。两者的分组方式、局部支持、BN数量和算力仍有差异，因此该结果证明本协议中的系统效果，不能唯一归因于层级性。HSTU 版本的97.48%是不同模型与阶段的既有结果，本轮不混作MHA对照基准。

S21 提出两个有界机制问题。H1 用固定可微插值把 Patch-Lite 的256点核扩展为340点，保持学习参数和32-token几何，将CNN局部支持从266扩展为350。H2 在原HStem中去除三个中间BN并重新训练，以检验这些归一化层在当前结构中的作用。H1改变滤波频响和成本，H2同时去除归一化和仿射作用；两项均不能单独提供完备因果识别。

实验遵循 P-H5x160 两个源/开发折，源每RX每TX为160训练包、40验证包；开发每RX每TX为200评价包。三个配对种子201/202/203，新增总计12次200epoch拟合。数据顺序、AWGN、优化器与源CE选模保持原配方，统一封存全部新模型后进行开发及历史confirm评价。重建原H0/P0并严格恢复其float32预测，报告所有种子和接收机。统计单位为RX，区间条件于这组种子；不以包数量或seed重复虚增独立样本量。

主要机制指标为H1相对P0恢复H0优势的比例；同时报告RX等权Accuracy/Macro-F1、最差配对RX变化、TX×RX错误变化。真类margin定义为真类logit减去最大非真类logit，包含误分类样本；最终64维特征的TX类中心距离用于辅助描述跨RX判别几何。参数、MACs和同GPU实测延迟共同评价轻量化，不从参数缩减推断加速。历史confirm已多次使用，最终创新主张还需要新协议/独立证据及更完整竞争文献核对。

S21 完成12次新增拟合。H0/P0/H1/H2 的 RX 等权开发准确率分别为 97.335% / 94.648% / 96.345% / 96.145%。H1−P0 为 +1.697 pp；H2−H0 为 -1.190 pp。

Overlap-Patch恢复了原HStem优势的63.151%，且两个开发折方向一致；插值同时改变局部支持、平滑和频响，尚不能唯一归因于重叠。去除中间BN导致6/6配对退化、开发准确率下降1.190pp，说明这些层对当前结构的训练或泛化有重要作用。两种因素均有证据支持，其贡献不可直接相加，不能强行归因于单一机制。


S22将H0 HStem+MHA固定为唯一主模型，RF-HSTU仅作Mixer对照。S1使用256→340→256固定线性插值与sqrt(256/340)尺度，全部256个基核位置有效，局部CNN支持为266；它是训练前针对中心裁剪秩亏问题作出的设计修订。S2将三个中间BN替换为初始化为1/0的通道仿射，保留352个参数、去除对应统计量，局部支持仍为350。两个新结构共12次拟合，按源CE选模后统一封存。

主要比较为H1−S1、S1−P0、H0−S2、S2−H2，采用事前固定的0.5pp实用门槛、两折方向、配对、RX区间与风险规则。全部比较共同报告，未作多重比较校正。时移和AWGN仅在冻结H0/P0的源验证包上进行，是有限压力测试，不是新的跨RX或盲测证据。
