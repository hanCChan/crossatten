# S22：最后一轮机制闭环与论文证据

本阶段承接S21，固定H0 HStem+MHA为唯一主模型。只新增S1与S2各六次拟合，两折×seed201/202/203，共12次200epoch；H0/P0/H1/H2共24个历史模型只读复用。完成后停止，不追加H3、核搜索、裁剪版本、新损失或blind评价。最终在独立实验分支提交代码、结果、论文表格、图示和审计。

训练前独立验收发现原方案中心裁剪的混杂：256→340后取42:298只依赖原核31:225，共194个位置；两端62个位置永久不进入前向，令19840个名义可训练参数无梯度。对应线性映射秩194。为避免把有效容量下降误当局部支持收益，本轮S1在任何拟合和新目标读取前改为满秩256→340→256往返插值。它不是原建议的中心裁剪模型；该区别必须在论文中保留。

S1两次插值均为linear、align_corners=False；仅在第一次插值后乘sqrt(256/340)，不追加幅值归一化。映射满秩、全部256个原核位置有梯度；可表示的256点核空间不缩小，变化集中在初始化与参数化/优化和滤波响应，不能把它当作训练后仍严格限制高频的低通。S1输出32×64 token，其余继承P0。

S2保留所有卷积、GELU、MHA及前端两个BN。每个替换模块只有`weight=1,bias=0`，无BN统计和running buffers；恰好保留352个仿射参数。保留参数的初始化逐元素与H0一致。

训练直接调用原S13 Shen200循环：TrueIB、五通道、batch64、200epoch、AWGN U[0,50)dB、AdamW1e-3/wd5e-4、warmup5/cosine，配对随机流与数据次序相同。仅源RX等权验证CE选checkpoint。原CUDA插值反向存在非确定性，数据/噪声与初始化保持配对，不承诺新增平滑模型训练逐比特重现。

四个主比较预先固定：H1−S1、S1−P0、H0−S2、S2−H2。探索性实用信号要求≥0.5pp、至少5/6正配对、两个开发折均正、条件RX95%区间下界>0、最差RX变化≥−2pp。等价信号仅在区间完全位于±0.5pp且两个折差值均在此范围内时报告；不显著不等于等价。四组全部报告，无多重比较校正，区间条件于现有种子。历史confirm只作描述。

先严格恢复24个旧模型的源验证结果，再执行登记拟合。全部12个checkpoint SHA统一提交封存后，才读取开发RX和历史confirm，旧模型的216组float32预测需逐元素严格恢复。技术失败保留现场并停止，不自动重训或换种子。评价器的真实流程已用临时合成数据覆盖，包括缺失输出目录的创建。

固定压力测试只在源验证包上比较H0/P0：clean、输入附加AWGN20/10/0dB、零填充时移−4/−1/+1/+4点。同fold/seed/条件共享扰动随机流，不用于模型选择，不是未见RX证据，不增加拟合。没有访问WiSig数据。

六台保留RX的历史资格只从已有协议文档检查。协议明确其曾被论文1用作盲测，不能称为全新未暴露holdout。本轮不打开或评价它们；未来测试仍需单独授权和历史披露。

执行入口：先`test_s22.py`和`s22_paper.py --prepare`，再`s22_register.py`，将设计和SHA提交后运行`s22_execute.py`。进度见STATUS.json和runs内live.json。后台从一开始隐藏运行，完成科学审计后再自动推送实验分支。最终产物为RESULTS.zh-CN.md、decision.json、FINAL_AUDIT.json、paper/和GitHub分支；未完成时不得把PREPARED稿件当成最终结果。
