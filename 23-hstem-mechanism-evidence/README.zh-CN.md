# S23：零训练机制证据收口

本阶段基于f856725，保持S13/S15/S21/S22全部科学结果与停止点不变。新增训练、架构搜索、优化器和blind/WiSig目标数据访问均为0。只恢复既有36个checkpoint，在每折原源验证集40包/TX/RX上分析，完成后停止，不自动启动S24。

固定检查包括：六个S1核物化为普通256点Conv1d、六个H0的三个tokenizer Conv-BN对折叠；所有源验证logits采用atol=rtol=1e-4，公开最大绝对误差、相对误差、预测一致数和失败，不因结果放宽容差。转换保留已训练函数，不等同于原P0或NoMidBN训练能找到同一权重。转换权重只保存在本地converted/，不作为新候选或新模型训练。

分析T和TTᵀ、有效首个分组核的1024点频谱与固定频带能量、全部36条既有200epoch轨迹。梯度只来自每RX×TX一个源验证包的50包均衡探针：冻结checkpoint、eval模式、交叉熵局部敏感性，无优化步。历史日志没有训练梯度，不能把新探针称作历史梯度轨迹。SGD预条件公式不直接套用于AdamW。

时移按±1/±4点同时报告零填充与循环移位，冻结H0/P0六组种子，每组使用相同2000个源验证包；循环±4另加固定“FFT幅度锁定为原包”内部诊断。该内部视图干预不代表物理信号，不用于主模型选择。逐层响应使用同一50包探针；只在时移是该层整数stride倍数时报告roll对齐误差。

代码核对的重要事实：FFT支路为log1p幅度并按包z-score，不显式保留FFT相位；另有atan2生成的时域相位通道。五通道把时域索引与频域索引按位置拼接，循环时移时两类坐标的变化规律不同。不能不经验证就把性能下降归因于FFT相位。

物理边界检查限于现有合法源验证8192点窗口、选择行号与已有采集文档：量化删除能量、包尾首连接、带限与循环移位交换性及DFT移位定理。若缺少真实同步时间戳和相邻采集样本，则明确无法把人工时移等同空口同步误差。循环移位守恒能量和幅度谱，也不自动等于真实连续采集。

本阶段审查论文1的本地PDF及既有代码来源，区分共有的TrueIB、五通道、CNN前端、32×64 token、汇聚分类结构与当前层级token/MHA/低预算协议。既有六台保留RX已在论文1使用，不能作为新独立blind。完整文字不上传；报告只给出处页码、摘要式比较和资格边界。

先运行test_s23.py，再登记registration.json并提交代码与SHA，之后运行s23_run.py。最终产物包括数学与数值等价性、核频谱、梯度/收敛、时移与边界、论文修订和中文二选一研究建议。统计均为既有源验证上的探索分析，不称独立确认。GitHub仅推送本独立分支的代码、图表和报告，不上传原始波形、转换权重或全文提取文本。
