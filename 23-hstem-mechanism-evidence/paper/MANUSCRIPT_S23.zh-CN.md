# 严格带内 LoRa 跨接收机识别中的轻量 RF token 形成：方法与实验初稿

本文研究严格零样本跨接收机、闭集10发射机识别，目标是用较少参数保留未见接收机上的身份判别能力。当前证据范围限定在 Shen LoRa 协议，不主张跨 LoRa/WiFi 的通用优势，也不将既有开发接收机上的后续消融视为独立盲测。

输入为8192点复数IQ。使用既有 RMS 标准化和 TrueIB 投影，从带内信号构造 IQ、FFT 与幅相视图，再经 k7/k5 的32通道局部前端形成特征。HStem 使用四阶段卷积，其前三阶段为 k8/s4/p2 的48、64、64通道卷积，分别接 BN 与 GELU，最后用 k4/s4 卷积得到32个64维 token。位置处理、Pre-LN 和分类头遵循既有实现，主机制研究统一采用两层普通 MHA。当前不把 HSTU 当作已证明必要的创新。

卷积构造 token 已有先例：[CvT（ICCV2021）](https://openaccess.thecvf.com/content/ICCV2021/html/Wu_CvT_Introducing_Convolutions_to_Vision_Transformers_ICCV_2021_paper.html) 将卷积引入视觉 Transformer；[Conformer（Interspeech2020）](https://doi.org/10.21437/Interspeech.2020-3015) 结合局部卷积与全局注意力。本文借鉴其局部与全局分工，但这些工作不构成当前 RF 机制的证明，不能据此声称卷积 token 化为首创。[Zhang（ICML2019）](https://proceedings.mlr.press/v97/zhang19a.html) 讨论下采样与平移稳定性，提供未来信号诊断背景；当前尚无依据将 HStem 宣称为已学习抗混叠或满足散射网络稳定性定理。

既有 S15 参数匹配结果中，HStem+MHA 为133690参数，Patch-Lite+MHA为134266参数，开发 RX 等权准确率分别97.335%和94.648%，差值+2.687pp，6/6配对为正。两者的分组方式、局部支持、BN数量和算力仍有差异，因此该结果证明本协议中的系统效果，不能唯一归因于层级性。HSTU 版本的97.48%是不同模型与阶段的既有结果，本轮不混作MHA对照基准。

S21 提出两个有界机制问题。H1 用固定可微插值把 Patch-Lite 的256点核扩展为340点，保持学习参数和32-token几何，将CNN局部支持从266扩展为350。H2 在原HStem中去除三个中间BN并重新训练，以检验这些归一化层在当前结构中的作用。H1改变滤波频响和成本，H2同时去除归一化和仿射作用；两项均不能单独提供完备因果识别。

实验遵循 P-H5x160 两个源/开发折，源每RX每TX为160训练包、40验证包；开发每RX每TX为200评价包。三个配对种子201/202/203，新增总计12次200epoch拟合。数据顺序、AWGN、优化器与源CE选模保持原配方，统一封存全部新模型后进行开发及历史confirm评价。重建原H0/P0并严格恢复其float32预测，报告所有种子和接收机。统计单位为RX，区间条件于这组种子；不以包数量或seed重复虚增独立样本量。

主要机制指标为H1相对P0恢复H0优势的比例；同时报告RX等权Accuracy/Macro-F1、最差配对RX变化、TX×RX错误变化。真类margin定义为真类logit减去最大非真类logit，包含误分类样本；最终64维特征的TX类中心距离用于辅助描述跨RX判别几何。参数、MACs和同GPU实测延迟共同评价轻量化，不从参数缩减推断加速。历史confirm已多次使用，最终创新主张还需要新协议/独立证据及更完整竞争文献核对。

# S22 完整中文研究判断

12次新增拟合、24个复用基线、36个模型的统一评价全部完成。所有新模型均训练200轮、按源RX等权验证CE选择checkpoint，统一封存后才评价开发RX与历史confirm。216组历史基线RX预测逐元素严格恢复，最终审计通过。没有重训基线、增加种子、开启H3、读取blind或WiSig原始目标数据。

| 统一MHA模型 | Dev Accuracy % | Dev Macro-F1 % | 历史Confirm Accuracy % |
|---|---:|---:|---:|
| P0 Patch-Lite | 94.648 | 94.625 | 93.367 |
| S1 Smooth-RoundTrip | 95.527 | 95.500 | 94.050 |
| H1 Overlap-Patch | 96.345 | 96.321 | 94.942 |
| H2 HStem-NoMidBN | 96.145 | 96.135 | 95.458 |
| S2 HStem-AffineOnly | 96.417 | 96.402 | 95.352 |
| H0 原HStem，冻结主模型 | 97.335 | 97.326 | 96.508 |

S1是训练前修订的满秩256→340→256往返插值，不是原方案中心裁剪。原中心裁剪映射秩194，会使62个基核位置、共19840个名义参数永久不参与前向。修订后的S1映射秩256，全部基核位置有梯度，可表示的256点核空间不缩小；因此它检验初始化、参数化与优化等组合效应，不是训练后强制低通的模型。该修订在读取本轮新目标结果前完成并预注册，没有训练裁剪候选。

## 局部支持：平滑参数化与额外支持都有增量证据

S1−P0为+0.878pp，条件RX95%区间[+0.547,+1.252]pp，5/6配对为正，两开发折分别+0.657/+1.100pp，最差RX增益+0.167pp，达到预注册实用门槛。这说明H1既有收益不能全部解释为扩大局部支持：不扩大支持的平滑参数化本身也有可观察收益。

H1−S1仍为+0.818pp，区间[+0.562,+1.053]pp，6/6配对为正，两折+0.860/+0.777pp，最差RX增益+0.050pp，同样通过实用门槛。历史confirm上差值+0.892pp，仅作描述。额外局部支持相关设计在当前平滑对照之外仍有增量证据，但两个算子的频响与参数化不同，不能把0.818pp称为纯重叠的因果贡献。

两项均值在代数上可相加得到H1−P0，但这只是同一组模型差值的恒等关系，不是两个独立机制贡献的因果分解。

## BN：额外仿射不足以恢复完整BN，统计与优化解释仍不完全

S2−H2仅为+0.272pp，区间[+0.135,+0.410]pp，5/6配对为正；它存在小幅正向差异，但低于事前0.5pp实用阈值，并落在预设的±0.5pp条件接近范围。历史confirm反而为−0.106pp。因此，不能把S21删除BN的损失主要归因于少了352个仿射参数。

H0−S2平均为+0.918pp，区间[+0.492,+1.295]pp，两个开发折均为正，但只有4/6配对为正，没有达到事前至少5/6的稳定门槛。该结果不能写成“完整BN没有收益”，也不能写成“统计归一化机制已经稳定证实”。历史confirm的+1.156pp、6/6为正仅提供描述性背景，不能用于补足开发集的晋级条件。

更准确的解释是：单独恢复仿射能力不足以恢复原HStem平均表现，BN统计及其训练动力学仍有线索；这些线索还没有排除优化差异和种子异质性。H0−S2最差RX变化为−0.717pp，H0也不是每个RX都占优。当前没有识别批统计、运行统计、优化与非线性的独立贡献或交互项。

## 参数效率与实际成本

H0有133690个参数，历史同协议完整Patch+MHA为571434个，参数减少约76.6%，Dev Accuracy从95.222%提高到97.335%。这是归档同协议系统比较，不是新的独立重复。相对参数匹配P0，H0平均高2.687pp，仍保留为预先冻结的主模型。

成本存在明确代价：H0计数MACs约95.028M，P0约55.346M；本次同机batch128 p50延迟分别16.123/13.453ms，单包p50分别2.510/2.281ms。MACs未完全计入FFT、插值和逐元素运算，延迟包含实际前向操作。只能主张较低参数预算下的准确率优势，不能主张所有效率指标均占优。最差RX等指标也不能只看均值排名。

## 论文结论与停止点

S22把S21的线索收紧为：RF token的参数化与局部支持相关设计均影响当前LoRa跨RX结果；只保留通道仿射不足以恢复完整HStem平均表现。纯重叠因果效应、BN统计与优化的分离、完整物理机制及跨数据通用性仍未建立。论文应完整报告门槛未通过、时移敏感和成本代价，不能以机制图或条件区间代替这些边界。

模型结构图、机制结果图、论文初稿、全部主表、逐RX/TX×RX、类别几何、压力测试、历史外部方法及审计均已生成。四项事前比较同时报告，无多重比较校正，区间条件于本组训练种子；不把seed或包当独立RX。

六台Shen保留RX在协议中有论文1使用历史，不具备“全新从未暴露holdout”的资格。本轮没有读取或评价它们。未来测试仍需单独授权并披露历史，不能自动升级为独立盲测。

# 可直接用于论文的S23修订文字

## 推理结构与训练参数化

本研究的往返插值tokenizer可写为有效卷积核v=Tw。固定变换T满秩，因此没有缩小256点核的函数表达空间，但改变了初始化和优化坐标。六个冻结S1模型物化为普通Conv1d后，在共12000个源验证样本上与原模型logits逐比特相同。这证明额外插值可从推理图移除，不证明原始P0训练算法必然获得相同权重。核谱、既有收敛轨迹与局部梯度提供优化相关线索，尚不能唯一归因于隐式正则化；SGD的TTᵀ几何解释也不是实际AdamW更新的精确公式。

## 归一化的训练与推理作用

冻结BN的统计与仿射可以代数折叠到前置卷积。实际数值验证区分两种执行条件：默认允许TF32卷积时，六个H0未通过预先固定的logit容差；禁用TF32后，六个模型均通过同一atol=rtol=1e-4，最大绝对误差约5.39×10⁻⁵。默认和严格精度的已测源验证分类均保持一致。这说明BN可在合适数值条件下作为训练时作用、推理时可消去的组件，但不等同于从头训练NoMidBN，也不证明BN去除了接收机信息。

## 同步与坐标敏感性的限制

在同一固定源验证包上，H0的Accuracy由98.175%降至循环−4/+4点下的21.858%/17.775%，与零填充结果接近；Patch-Lite同样严重退化。因此，不能把问题仅解释为补零边界或HStem独有的层级下采样效应。原始循环移位保持能量和DFT幅度，RMS/带限的交换误差接近浮点精度；把FFT幅度视图锁回原包也几乎不改变结果。当前FFT输入是幅度而非显式频谱相位，时域atan2相位和混合时间/频率索引的共同表示仍对移位敏感。该结果定位了表示与位置敏感性，尚未识别唯一通道或物理硬件来源。

现有源记录为8192点定长窗口，未提供邻接连续样本、包检测时间戳或真实同步偏移分布。循环移位虽保留离散内容，也不能自动等同实际空口同步误差。本文的效果主张限定于当前已截取、已对齐协议；不宣称一般同步鲁棒、抗混叠或接收机硬件不变性。

## 贡献与独立证据边界

相对前一篇OOB依赖诊断工作，本研究问题转向严格带内、有限源预算下的token形成与参数效率。TrueIB、五通道前端、32×64 token及同一LoRa语料存在明确继承，应逐项说明来源。较低参数与较高同协议准确率不意味着所有MACs/延迟更优，转换后的默认精度延迟也不能替代严格精度数值等价条件下的性能测试。当前所有S23结果均为既有源验证上的探索分析；六台保留RX有前文使用历史，不构成全新独立holdout。

本轮证据足以完成限定范围的稿件，并应结束逐层机制拆解。若今后追求同步鲁棒的新方法，需先用新的采集/同步信息验证物理干预条件，再单独冻结新假设和独立评价协议，不根据本轮结果自动追加训练。
