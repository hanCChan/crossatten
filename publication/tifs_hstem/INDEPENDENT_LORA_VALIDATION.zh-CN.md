## 独立性准入

1. 由采集方核对与原任务一致的十台物理 TX，交付原设备编号与登记标签映射。原任务是闭集评价，标签对应的是设备实例。
2. 在读取波形前，登记物理接收机 ID 和型号、采集时地及会话标识、与历史语料的关系、信号配置、同步方式和文件摘要。分别标注全新 RX、已有 RX 的新会话和其他变化，以对齐拟主张的独立性。可行时优先覆盖多个新物理 RX、两类以上硬件和重复会话。
3. 采集连续信号或保留能还原包位置的元信息。提供 SF7、125 kHz、1 MHz、8192 样点输入的合法取得或确定性转换方案。预先固定剪裁、增益、接收失败计数及窗口纳入条件，保留排除包的理由。

## 冻结评价

打开 IQ 前，固定可用 RX 与会话清单、已登记 TX、原始文件 SHA-256、纳入条件、推理版本和统计方案。以现有两个源 RX 视图、三个种子共六个源域选中 checkpoint 为冻结队列，对共同包集一次评价。HStem、Ma Spec+Siamese 和 Shen-DANN 用于 Native 比较，同支持 Long-Patch 用于结构对照。提前绑定现有权重哈希和原有前端，逐包保存共同 ID、标签及各模型预测。

主指标是 RX 等权准确率。主配对比较为 HStem−Spec+Siamese，HStem−Shen-DANN 和 HStem−Long-Patch 提供部署和结构对照。先按同一 RX 内的会话等权汇总配对结果，再对物理 RX 等权汇总，并报告各 fit。同步报告 Macro-F1、逐 RX 与逐会话指标、每个方法的最差 RX、配对差区间、包检测成功及排除计数。物理 RX 很少时逐台报告，区间仅用于描述本次采集批次。

分析时同时记录对齐后的分类准确率和可用窗口覆盖。新日期和新 RX 同时变更时，结果解释为本次联合变化下的验证。评价保持单次冻结。模型、阈值和确认集划分均在查看确认分数之前定稿。
