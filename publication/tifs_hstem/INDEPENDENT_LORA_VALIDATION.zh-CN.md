# 独立 LoRa 冻结评价方案草稿

当前状态为待获取来源和采集。现有工作区的历史清单和文件名未提供可确认的新接收机采集。旧六台盲测 RX 已服务于先前工作。公开语料的 Location 后缀不能证明它是新物理接收机或未用于开发。

## 独立性准入

1. 由采集方核对与原任务一致的十台物理 TX，交付原设备编号与登记标签映射。原任务是闭集评价，标签对应的是设备实例。
2. 在读取波形前，登记物理接收机 ID 和型号、采集时地及会话标识、与历史语料的关系、信号配置、同步方式和文件摘要。分别标注全新 RX、已有 RX 的新会话和其他变化，以对齐拟主张的独立性。可行时优先覆盖多个新物理 RX、两类以上硬件和重复会话。
3. 采集连续信号或保留能还原包位置的元信息。提供 SF7、125 kHz、1 MHz、8192 样点输入的合法取得或确定性转换方案。预先固定剪裁、增益、接收失败计数及窗口纳入条件，保留排除包的理由。

## 冻结评价

打开 IQ 前，登记可用 RX 与会话清单、已登记 TX、原始文件 SHA-256、评价支持量、HStem 和同支持 Long-Patch 的全部已选权重哈希、推理版本、统计及晋级规则。共同支持的冻住的包集用于所有配对模型。源域已确定的预处理和分类头直接运行，同批锁定各模型的输出。

主指标为 RX 等权准确率上的 HStem−Long-Patch 配对差。在每台物理 RX 内按确立的会话权重平均配对结果，再按 RX 分组汇总。同步报告 Macro-F1、每台 RX 和会话、最差 RX、差值区间、包检测成功及排除计数。RX 单元很少时逐台报告，区间仅作为本次采集批次的描述。

分析时同时记录对齐后的分类准确率和可用窗口覆盖。新日期和新 RX 同时变更时，结果解释为本次联合变化下的验证。评价保持单次冻结。模型、阈值和确认集划分均在查看确认分数之前定稿。
