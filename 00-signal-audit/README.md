# 00 数据与信号审计（不训练任何模型）

## 目的

在训练任何模型之前，先在信号层面回答三个问题：
1. 数据到底是什么：采样参数、对齐方式、是否做过 CFO 补偿、8 个 chirp 是否重复。
2. 各个频段里有没有周期信号；有的话，这些信号在单台 RX 内部和跨 RX 时各含多少设备身份信息。
3. 哪些元数据或频段可能构成捷径（SNR、CFO、噪底）。

这些结论决定后续预处理的候选设计，例如保留哪个频段、要不要做相干平均。**它们只是候选，不直接当作结论写进论文。**

## 数据范围与防泄漏

- 只读取协议中 10 台 source/dev_val 接收机的 `_train.h5` 文件，每台 2000 个包。4 台确认 RX 和 6 台历史盲测 RX 都不读：前者被 guard 按用途拒绝，后者按文件名拒绝。
- 包的抽取规则与 rl1 的 g1_cache_v1 完全相同：seed 20261012，每个 TX 取 200 包。[00-1-build-cache.py](00-1-build-cache.py) 已逐字节核对 10 台 RX 的 I/Q、行号和标签与 rl1 缓存一致，源文件的 SHA256 也与登记值一致。
- 确认 RX 的缓存（b200_1、n210_1、rtl_4、rtl_8）同样已经生成，但除了完整性检查（形状、标签计数、SHA）外，没有对它们计算任何统计量。

## 方法与理由

| 分析 | 做法 | 为什么这样做 |
|---|---|---|
| A 物理核验 | 1. 用理想 SF7/125 kHz/1 MHz 的 upchirp 对每个符号做 dechirp，再看 FFT 峰的位置和能量集中度。<br>2. 计算 8 个符号相干平均后保留下来的能量比例。<br>3. 计算频谱质心，并与 CFO 字段比较。<br>4. 计算每个符号相对均值 chirp 的残差，以及相邻符号残差之间的相关系数。 | 1. 只有 Fs、BW、SF 和符号边界都对，dechirp 后的能量才会集中在 bin 0，所以这一步同时核验了频率坐标。<br>2. 用来检验"8 个 chirp 是否几乎一样"。<br>3. 用来判断 CFO 是否已经被补偿掉。<br>4. 如果残差只是独立噪声，相邻残差的相关系数理论上是 −1/7。显著偏离这个值说明残差里有缓慢漂移这类确定性成分，此时相干平均会把它们一起抹掉。 |
| B 梳状谱剖面 | 在 8192 点 FFT 中比较每 8 个 bin 一个的梳状频点与其余频点的平均功率比，按 25 kHz 一段、左右两侧分别统计。 | 8 个重复 chirp 构成的周期信号只会出现在梳状频点上，非梳状频点只含非周期成分（噪声、符号间变化）。所以这个比值大约 0 dB 的频段，意味着那里没有可检测的重复信号。 |
| C 频段信息探针 | 1. 把每 32 个 bin（3.9 kHz）分为一组，分别取梳状频点和非梳状频点的 log 功率作为特征，训练线性 logistic 回归。<br>2. 设两种评估：单台 RX 内（160 包/TX 训练，40 包/TX 测试）和跨 RX（按协议 fold，5 台源 RX 训练，5 台 dev_val RX 测试）。<br>3. 额外测试三种一维特征：频段相对 IB 的功率比，以及 SNR、CFO 两个元数据字段。 | 1. 回应"不能只看 0 dB 就删掉远带"这一要求：直接测每个频段含多少可迁移的身份信息。<br>2. 线性探针只给出粗略的信息下限，不代表深度模型能达到的上限。 |
| D SNR 捷径 | 计算 SNR 字段和远带功率对类别的 η²（类间方差占比），以及远带功率与 SNR 字段的 Spearman 相关。 | 在固定位置采集时，每个 TX 的 SNR 基本是常数，因此 SNR 本身就可能是一个分类捷径。 |
| E CIS 坐标 | 计算 Shen 所用 STFT（窗长 128、boxcar）每一行对应的真实频率，看 chirp 能量实际落在哪几行，并确定 crop 的频率范围。 | 回应"必须用官方代码的真实频率坐标核查"这一要求：用实测的信号位置来核验，而不是从数组下标推算。 |
| F 均值 chirp 与残差 | 把 8 个符号的均值 chirp 和逐符号残差的频谱分别做成特征，用同样的线性探针测。 | 为方向 B（相干平均）做准备：看相干平均会不会丢掉身份信息。 |

运行：
```bash
python 00-signal-audit/00-1-build-cache.py
python 00-signal-audit/00-2-signal-audit.py
```
输出在 `out/`，结论见 [RESULTS.md](RESULTS.md)。
