# 00 信号审计：结果与解读

数据范围：10 台 source/dev_val RX，每台 2000 个包。确认 RX 与盲测 RX 均未参与。线性探针在 10 类上的随机水平是 10%。
原始输出见 [out/00-2-audit.json](out/00-2-audit.json)，运行日志见 `logs/00-2-audit.log`。

## A. 数据本身（物理核验）

| 检查项 | 结果（10 台 RX） | 结论 |
|---|---|---|
| dechirp 后峰值落在 bin 0 的比例 | 0.994–1.000 | 所有包都与 chirp 边界对齐，同时证实 Fs=1 MHz、BW=125 kHz、SF7（参数错了能量不会集中） |
| dechirp 后最大 3 个 bin 的能量占比 | 0.878–0.885 | 其余约 12% 的能量是带边泄漏、硬件失真和噪声 |
| 8 个 chirp 相干平均后保留的能量 | 0.996–0.997 | 8 个 preamble chirp 几乎完全相同 |
| 频谱质心 | USRP/Pluto 为 −40 至 −477 Hz；**RTL 为 −1.5 至 −1.8 kHz** | 存储的 IQ 已做过 CFO 补偿（质心与 CFO 字段的 ρ 在 −0.27 至 +0.07 之间）。但 RTL 系列有一个共同的约 −1.7 kHz 残余偏移，属于接收机相关的干扰因素 |
| 各符号残差能量（相对均值 chirp） | 第 1 符号 0.012–0.013；中间符号 0.0004–0.0009；第 8 符号 0.004–0.006 | 呈 U 形：第一个符号有明显的开机瞬态，首尾两端偏离均值最多，说明包内存在缓慢漂移 |
| 相邻符号残差的相关系数 | **+0.49 至 +0.67**（若为独立噪声应约为 −0.14） | 残差主要不是白噪声，而是确定性的慢漂移和瞬态 |

**对方向 B 的含义：** 相干平均确实能压低独立噪声，但残差里有确定性的瞬态和漂移。这两者在 RFFI 文献中本身就是经典指纹。所以"只保留均值 chirp"会丢掉信息，后续设计必须保留**均值 chirp + 残差（或首个符号）分支**。下面 F 节的探针结果直接支持这一点。

- **频谱明显不对称**：右侧的周期带外信号一直延续到约 200 kHz，左侧在约 100 kHz 处就已经衰减到噪声水平。所有 RX 都如此，各 RX 之间的差别很小。
- \|f\|>200 kHz 的两侧都检测不到周期信号。之前提出的 200 kHz 边界是对右侧而言的；左侧的有效边界约为 100 kHz。

## C. 各频段的类别信息（线性探针准确率：单台 RX 内 / 跨 RX）

| 频段 | 梳状特征 | 非梳状特征 | 一维功率比 |
|---|---|---|---|
| IB (\|f\|≤62.5k) | **71.2 / 73.8** | 50.9 / 54.1 | – |
| 近带 62.5–100k（左右合并） | 67.3 / 52.6 | 62.1 / 36.1 | 42.9 / 36.7 |
| 　其中左侧 | **64.3 / 49.1** | 60.6 / 33.7 | 40.8 / 31.4 |
| 　其中右侧 | 24.3 / 21.0 | 15.4 / 12.6 | 12.9 / 12.1 |
| 中带 100–200k | 31.4 / 24.6 | 36.2 / 19.7 | 21.0 / 11.9 |
| 远带 >200k | 23.3 / 18.1 | 24.9 / 15.7 | 28.7 / 14.7 |
| SNR 字段（一维） | – | – | 33.8 / **8.9** |
| CFO 字段（一维） | – | – | 62.8 / **10.0** |

解读：
1. **近带外（62.5–100 kHz）确实含有可迁移的身份信息**，而且几乎全部集中在**左侧**。右侧虽然周期能量更强，类别信息却少得多。这与论文 1 的发现一致：左侧衰减造成的掉点远大于右侧。一个可检验的物理假设是：每个 upchirp 结束时频率从 +62.5 kHz 跳回 −62.5 kHz，这次跳变后的锁相环/滤波器建立过程落在下带边。这一点尚未证实，阶段 02 会用"按 chirp 内时间位置分解"的方法来检验。
2. **远带（>200 kHz）的信息并不为零**：单台 RX 内 23–29%，高于 10% 的随机水平。但跨 RX 时只剩 15–18%，迁移性差。其中，一个标量（远带/IB 功率比）在单台 RX 内就有 28.7%，说明这部分信息主要来自噪底/SNR 水平，而不是谱形。所以结论不是"远带没有信息"，而是"远带信息主要是与 RX 绑定的 SNR/噪底类捷径"。这一点要在阶段 01 用 Q3 的频带实验在真实模型上检验。
3. **元数据是强捷径，但完全不能跨 RX 迁移**：CFO 字段在单台 RX 内能达到 62.8%，跨 RX 为 10.0%（随机水平）；SNR 字段单台 RX 内 33.8%，跨 RX 为 8.9%（低于随机，即反向迁移）。因此按决策，CFO/SNR 不进入主模型，这一决策有数据支持。

## D. SNR 捷径（各 RX 的 η² 与相关系数）

| 指标 | USRP/Pluto（3 台） | RTL（7 台） |
|---|---|---|
| η²(SNR 字段，按类别) | 0.51–0.65 | 0.83–0.98 |
| η²(远带功率，按类别) | 0.07–0.19 | 0.26–0.80 |
| Spearman(远带功率, SNR) | −0.23 至 −0.41 | −0.41 至 −0.90 |

RTL 接收机（8 位 ADC，噪底较高）上，远带功率几乎等价于 SNR 的代理变量，而且 SNR 本身就能区分设备（发射机位置固定）。这就是远带 OOB 成为"接收机相关捷径"的机制假设。

## E. Shen CIS 的真实频率坐标

- STFT 的行 i 对应频率 (i−64)×7.8125 kHz。实测 chirp 能量在峰值 10 dB 以内的行恰好是 56–72，即 −62.5 至 +62.5 kHz。这说明坐标正确，而且是用信号实际所在位置核验的。
- Shen 的裁剪保留第 38–89 行，即 **−203.1 至 +195.3 kHz**，共 52 行，其中 **36 行位于 IB 之外**。所以 Shen-CIS 并不是带内表征；它恰好保留了左右两侧都含周期信号的近/中带，丢掉了 >200 kHz 的纯噪声区。
- 裁剪范围本身也左右不对称，相差 1 个 bin。

## F. 均值 chirp 与残差的信息（单台 RX 内 / 跨 RX）

| 特征 | IB | 62.5–200 kHz |
|---|---|---|
| 均值 chirp 频谱 | 71.2 / 73.8 | 62.8 / 50.2 |
| 逐符号残差频谱 | **50.7 / 52.5** | 68.8 / 28.9 |

- IB 内的残差含有约 51–53% 的身份信息，并且能跨 RX 迁移。这部分正是相干平均会丢掉的东西，因此不能只用均值。
- 带外的残差在单台 RX 内信息很多（68.8%），但跨 RX 只有 28.9%，与 RX 绑定得很紧。
