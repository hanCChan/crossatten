# Final completed evidence

All registered fits in this snapshot are complete. See MANIFEST.json for phase counts, checkpoint hashes, per-file hashes, and publication time.

Each run includes its config, full training history and metrics. Formal LoRa runs also include dev_val and historically used confirm receiver outcomes. data_access.jsonl contains access metadata only.

All checkpoint hashes were verified against local files. Accuracy and Macro-F1 were recalculated from saved confusion matrices; source checkpoint seals, registered code and access roles were checked. Checkpoint binaries, IQ data and credentials are excluded. Text line endings are normalized to LF.

Smoke fits are engineering checks, not accuracy evidence. A source-gate STOP is retained and does not authorize target CRD or additional confirmation.
