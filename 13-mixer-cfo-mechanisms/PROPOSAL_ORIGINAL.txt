## 二、LoRa：应该先补普通 Attention 对照，但需要比一个模型更多一点

这是我最优先推荐补的实验。它的目标不是刷新排行榜，而是提高第二篇论文的架构创新可辩护性。

### 1. 现有代码究竟实现了什么？

我检查了实际实现文件：

[legacy_rfhstu/models.py](https://github.com/hanCChan/crossatten/blob/exp/s12-spectral-validation/lib/legacy_rfhstu/models.py?utm_source=chatgpt.com)

目前 RF-HSTU 的核心是：

\\[ A=\operatorname{Sigmoid}\left(\frac{QK^\top}{\sqrt d}+B\_{\rm rel}\right) \\]

\\[ Y=\operatorname{LN}\left[X+W_o\left(\operatorname{LN}(AV)\odot\operatorname{SiLU}(U)\right)\right] \\]

它与普通 Transformer 的最重要区别是：

- 使用 Sigmoid 而不是 Softmax 归一化注意力。
- 通过 \\(U\\) 对聚合特征进行逐元素门控。
- 使用相对位置偏置。
- 没有标准 Transformer 中独立的 FFN 子层。

需要注意，ICML 2024 的原始 HSTU 使用的是对 Attention Score 逐元素施加 SiLU，而你的实现采用 Sigmoid。应当称为 RF-HSTU 或 HSTU-inspired Gated Mixer。

### 2. 你师弟的频偏校准究竟在做什么？

收到的信号可用简化形式表示为：

\\[ r[n]=h[n]\*s\_{\mathrm{TX}}[n]\\, e^{j2\pi\Delta f\_{\mathrm{obs}}n/f_s}+w[n] \\]

其中观测频偏近似由发射机与接收机本振共同决定：

\\[ \Delta f\_{\mathrm{obs}}\approx f\_{\mathrm{TX}}-f\_{\mathrm{RX}} \\]

所以模型可能把发射机的频偏、接收机的频偏、信道和硬件失真混在一起学习。

示意：真正的目标不是简单消除所有频偏，而是保留与发射机身份相关的信息，同时抑制接收机差异。

最困难的地方在于：从单个未知 TX 的接收包中，通常不能唯一分离出 TX 频偏和 RX 频偏。

如果直接将每个包的总频偏全部校正到零，确实可能减少 RX 差异，但也可能把 TX 振荡器本身具有判别力的频偏特征一起删除。

因此，“对齐到统一频率后让模型对频偏更敏感”并不是必然成立的物理机制。更合理的说法是：

对齐接收机相关的公共频率偏移，同时通过原始支路或残差信息保留可能具有 TX 判别力的特征。

### 3. 有一个适合 WiSig 的具体切入点：利用 WiFi STF 重复结构估计 CFO

WiSig 官方提供的非均衡数据保留前 256 个前导码样本；其均衡版本的处理流程本身就包含基于 STF 的包起点检测和频偏校正。

[image](https://www.google.com/s2/favicons?domain=https://cores.ee.ucla.edu\&sz=32)

CORES Lab - UCLA+1



利用周期为 \\(L\\) 个采样点的重复信号，可以尝试：

\\[ \widehat{\Delta f} =\frac{f_s}{2\pi L} \arg\left( \sum_n r[n+L]r^\*[n] \right) \\]

在你当前 WiSig 25 MHz 采样率下，名义 WiFi STF 的 0.8 微秒重复周期对应约 20 个采样点。

但需要先审计：未经均衡的包是否确实有足够、对齐正确的 STF，估计的置信度如何，低 SNR 时是否有偏，以及对不同 TX 的估计是否系统性偏移。

我建议先做 CFO 估计器验证，不直接修改分类网络。

### 4. 浅层适配应该怎么理解？

你师弟提出“只微调第一层，效果与微调整网相近”，其可能解释至少有三种：

1. 接收机引起的幅度、相位、频率响应差异主要在浅层表征中可被校正。
2. 深层本来已经学到较稳定的 TX 判别空间，微调浅层就足够。
3. 微调整网容易过拟合少量数据，浅层微调更受约束，因此表现相近。

这三种情况的科研结论完全不同。

需要先检查 BatchNorm 统计、浅层权重、特征分布和 TX/RX 可分性，才能支持其中一种解释。

还有一个协议问题非常重要：

| 方法                    | 使用目标 RX 无标签数据？ | 应该归入                       |
| --------------------- | -------------- | -------------------------- |
| 模型冻结，直接预测             | 否              | 严格 0-shot DG               |
| 逐包固定信号处理，不跨包学习目标统计    | 不需要目标校准集       | 可以纳入预先冻结的 DG 处理流程          |
| 使用一批目标 RX 无标签包估计公共频偏  | 是              | 测试时校准 / Transductive       |
| 使用目标 RX 无标签包更新第一层或 BN | 是              | UDA / Test-Time Adaptation |

这并不意味着后两种方法不好。它们解决的是真实部署时降低接收机适配成本的问题，而且已有跨接收机 RFFI 文献明确研究无标签目标域适应，例如 2025 年的 CSCNet；跨领域通用基线 Tent 也使用测试数据更新归一化统计和参数。

[image](https://www.google.com/s2/favicons?domain=https://pmc.ncbi.nlm.nih.gov\&sz=32)

pmc.ncbi.nlm.nih.gov+1



只是它们的结果不能直接与目前严格禁止目标数据参与的 ASKNet 88.77% / 93.48% 混排。

因此，我建议这篇第二论文优先继续严格 0-shot DG；你师弟的浅层无监督适配作为独立扩展实验，未来可以成为另一条有价值的论文方向。

## 四、下一轮实验：我建议按四个阶段执行

不要把 LoRa 注意力消融、CFO 校准、浅层适配和新 Loss 同时混进一组训练。那样即使指标上升，也无法判断哪项改动有效。

建议执行顺序

P0 · WiSig 失效机制诊断

浅层 RX 信息、BN、真实 CFO 分布

P1 · LoRa 架构证明

RF-HSTU vs MHA / Transformer

P2 · WiSig 泛化优化

CFO 扰动与双支路表征

P3 · 独立扩展：浅层无监督适配

仅在源接收机模拟环境验证，另设 UDA 协议

### P0：先确认 RX 差异是否主要集中在浅层

先使用 WiSig 源 RX 日期 1–2，不读取真实目标 RX 数据。

具体检查四类信号：

| 测量对象      | 具体做法                          | 想验证什么           |
| --------- | ----------------------------- | --------------- |
| 各层 TX 可分性 | HStem 各层、HSTU 输出训练轻量 TX Probe | 哪一层开始形成稳定 TX 特征 |
| 各层 RX 可分性 | 在控制 TX 类别的条件下训练 RX Probe      | 是否存在显著接收机表征     |
| 各层 RX 扰动  | 比较相同 TX、不同源 RX 的特征位移          | RX 差异主要出现在哪里    |
| BN 与浅层敏感度 | 仅改变 BN 统计、仅改变 Stem、冻结其他层      | 浅层权重还是归一化统计在起作用 |

对不同层的特征距离需要统一尺度，不要直接比较未归一化激活的欧氏距离。

最有说服力的结果不是单独一张 t-SNE，而是绘制各层的 TX 类间分离度和 TX 条件下的 RX 差异，例如：

\\[ \rho_l=\frac{D\_{\mathrm{RX},l}}{D\_{\mathrm{TX},l}+\epsilon} \\]

其中 \\(l\\) 是网络层，两个量需使用一致的归一化和样本加权方式。

如果浅层的 \\(\rho_l\\) 高、深层明显降低，并且浅层受控适配确实改善源 RX 留出测试，就形成了两方面相互支持的证据。

但这仍不能单独证明 RX 影响在深层彻底消失。

P0 的输出必须是一份机制诊断报告，而不是新模型准确率排行榜。

### P1：LoRa 结构实验

在现有 Shen P-H5x160 协议下运行第二节的 A0–A4。

建议沿用 2 folds × 3 seeds 的正式组合。为保证完全配对，必要时重训旧基线，而不是拿不同历史 seed 的汇总值直接做差。

这项实验只应改变 Mixer，不能同步改变 Stem、输入视图、AWGN、训练轮数和选模逻辑。

主要交付物是：同协议准确率、Macro-F1、最差 RX、参数量、MFLOPs、实测延迟、配对差值和不确定性。还要特别注意，你的 HStem 虽然参数更少，但历史报告中其 FLOPs 和实测延迟并不优于普通 Stem，不能简单宣称整体更快。

### P2：WiSig 优先研究两种不同的 CFO 方法

我建议先比较两个可区分的候选，而非直接开展复杂的网络搜索。

候选 B1：源域物理 CFO 随机化

在训练时施加基于源域实际频偏分布设定的随机旋转：

\\[ x'[n]=x[n]e^{j2\pi\delta f n/f_s} \\]

目标是提高对频偏扰动的稳定性，而不是完全删除 CFO。与历史普通 AWGN 增强区分开，保留发射机类别标签不变。

候选 B2：原始 IQ + CFO 校正 IQ 双支路

一路保留原始观测，另一路进行每包确定性频偏校正。通过轻量门控或特征融合保留两者的互补信息。

这种设计的核心假设是：校正支路提供较稳定的结构特征，原始支路保留可能具有 TX 判别力的硬件残差。

不需要目标 RX 的批量统计或在线更新即可进行首次验证。

B1 需先审查仓库里已经实现的 CFO augmentation，确定此前是否有同一配置的实验，避免重复劳动。B2 应设置 raw-only、corrected-only 和 dual-branch 三组对照，且与参数匹配的双原始支路控制比较，证明不是单纯增加参数而涨分。

在初步试验中可以先采用两个数据集、四个源 RX folds、一个留出分组、一个种子，并对候选和相应基线配对重训。

我建议预注册下一阶段的晋级条件为：

| 条件                | 建议标准             |
| ----------------- | ---------------- |
| ManyRx 平均源留 RX 增益 | 至少 +1.0 pp       |
| ManyRx 正向 folds   | 至少 3/4           |
| 最差 RX 平均退化        | 不超过 −2.0 pp      |
| ManySig           | 不出现稳定的系统性退化      |
| 独立确认              | 使用新种子、另一个留出分组再验证 |
| 真实 CRD            | 只在全部源域决策冻结后评估    |

这些是我建议的新预注册标准，不是已经完成的实验或事后改变 S12 门槛。

如果 CFO 增强和双支路都未通过源域门槛，就停止这条方向，不以目标域成绩补救。尤其不能只因为 ManySig 上升，就忽略 ManyRx 的负结果。

### P3：浅层适配作为独立方向验证

如果 P0 确实支持“浅层 RX 偏移”假设，再基于源 RX 内部模拟新接收机部署建立第二套实验。

| 对照 | 允许更新的内容         | 目的           |
| -- | --------------- | ------------ |
| C0 | 无更新             | 直接部署基线       |
| C1 | BN 统计量          | 区分统计偏移和权重偏移  |
| C2 | BN 仿射参数         | 测试低成本校准      |
| C3 | 第一层卷积或小 Adapter | 浅层适配         |
| C4 | 全模型             | 适配能力上界，但易过拟合 |

这里必须使用相同的预训练模型作为起点，控制适配样本数、优化步数和访问的数据。

对于无标签版本，可以考虑熵最小化和一致性约束，但已有 Tent 和 RFFI source-free adaptation 工作，所以不能将“只更新浅层”本身包装成从未出现过的新算法。

另外，不能先用源 RX 的真实标签调好模型，再把对应结果称为无监督适配。带标签微调只能作为单独的 Oracle 上界。

## 五、扩展思维：如果 CFO 方向不成功，还可以研究什么？

在 P0 机制结果出来前，我会保留另外两个候选，但不同时投入大规模训练。

方向一：面向接收机失真的源域物理扰动建模。

与简单随机加噪声不同，可以从合法源 RX 中估计接收链差异的合理幅度范围，构造频率选择性增益、相位响应或 IQ 失衡扰动，再对同一 TX 样本进行受控增强。

重点是避免生成不符合真实接收链约束的任意频谱形变。已有代码中存在相位、时移、CFO、channel augmentation，因此应先核实历史结果，再决定是否有真正不同的新机制。

方向二：只对浅层建立接收机鲁棒表示，而不是强制整个网络不含 RX 信息。

例如设计一个轻量、固定推理成本的前端，使同 TX 不同源 RX 的浅层表示接近，同时保持不同 TX 的判别间隔。

可以考虑源域多 RX 条件下的类条件对齐，或者以源 RX 模拟扰动形成一致性训练对。但这些方法已有相关先例，特别是 RIEI、IB-RFF 和 2026 年的平衡域对齐研究；贡献应放在具体的 RF 机制、适配位置和受控收益，而不是宣称首次进行特征对齐。

## 八、最终的研究路线判断

我的优先级是：

第一优先：LoRa 上补充 RF-HSTU 与普通 Attention 的消融。 这是现有第二篇论文最容易补强、且直接回应审稿人质疑的一项工作。

第四优先：浅层无监督适配。 这可以发展成独立的低成本部署研究，但应该使用单独协议和相应的 UDA/TTA 强基线。
