# S31 源域尺度 CFO 增强

直接复用 S29-R 的两套 ManyRx 源域划分、两个种子、8 份选定权重，以及 S30 同包响应。两结构 × 两视图 × 两种子新增 8 次增强训练。只允许 S29 原 fit_train 更新参数和 BN，checkpoint_val 读未扰动包、等 RX 的 CE 最小时选模，全部模型封存后才访问新模型的 source_selection。外层目标 RX、D3/D4、ManySig、Shen 无新增数据访问。

唯一训练变量为逐包在线 CFO 注入。每次访问以 0.50 概率选中，选中时均匀抽取 −2500 至 +2500 Hz，在 IQ 层乘 exp(j 2π Δf (n−127.5)/25e6)。未选中样本保留原五通道频谱字节。独立 CUDA 随机流 seed=31201+100×view+seed。两种 tokenizer 对相同样本顺序使用相同掩码和频偏。无时移、天然频偏归零、额外损失、额外梯度更新或数据复制。2.5 kHz 来自 S30 的源域 RX 相关项尺度，均匀扰动是训练设计。

复用 S29 原 FP32 训练循环、后端、batch128、40轮、Adam lr=.001/wd=.001、Plateau 规则。模型初态与配对基线逐字节相同。每组 5,080 更新、合计 40,640。仅原始输入验证选模。

主端点为未扰动包 RX 等权 Accuracy。报告两臂增益 G_H、G_P、交互 G_H−G_P、增强后结构差，保留两套视图、全部 seed、逐 RX 和逐 TX 结果。RX 先平均同一 RX 的两 seed，再按视图分层配对重抽 10,000 次（seed24501）。条件区间描述当前历史受体及固定种子。最差配对 RX 和最差绝对准确率均先平均同 RX 两 seed 再取最小值。

增强 HStem 晋级需同时满足未扰动平均增益≥1 pp、区间下界>0、至少3/4个视图×种子配对为正、两视图均正、最差配对 RX≥−1 pp、最差绝对 RX 不低于基线、RX 等权 Macro-F1 不降、0–5 kHz 的中心锚定准确率平均损失曲线面积不增、部署参数量及前向路径一致。面积用 S30 固定网格 0/1/2/2.5/5 kHz、正负等权、梯形积分除以范围，所有损失以各臂自己的干净表现为基线。报告曲线各点的绝对受扰准确率，用以区分基线下降造成的表观鲁棒性。交互独立报告配对区间，均值为正不单独作为互补证据。没有额外训练、参数选择或正式 CRD。
