# M0：WiSig Raw/EQ 同包视图的有界前置核验

目标是判断**当前本地材料**是否足以支持真实同包双视图研究。这里的 Raw 指未均衡的 256 点 Id signal；不是未分包、含空闲和 ACK 的完整 Raw WiSig 采集流。M0 不训练新分类器，不追加 A/B 因素归因，不改变历史 STOP。

本登记发生在首次查看官方处理代码和已有 D4 文本之后、任何本工作包科学载荷或性能结果之前。已看到的代码事实不能伪装为盲态预注册。机器可读边界见 [PRE_REGISTRATION.json](PRE_REGISTRATION.json)；提交由主代理完成，当前登记本身不授权打开科学载荷。

## 本轮范围与出口

只查官方网页、固定提交的处理/子集代码、已有 D4 与本地来源/字段元信息、文件目录及 ZIP 中央目录。不解码 IQ，不完整加载 pickle，不调用现有科学加载器或索引器，不读权重和预测，不下载科学数据。潜在合法科学范围仅限 fold2 fit18、2021-03-01/03-08、原十 TX、每原始 cell 前 100 包；这只是权限上限，不是本轮载荷放行。

按顺序核验下列门槛，任一前置失败即封存，不改名重试、补训练或继续探针：

| 门槛 | 必须满足的证据 | 未满足的处理 |
|---|---|---|
| G0 来源与操作 | UCLA 官方来源；固定代码版本；区分未均衡 Id signal 与完整 Raw 采集 | 明确证据缺口 |
| G1 本地逐包身份 | 唯一 detected-packet ID / capture+start-offset，或有来源且保留原索引的映射；贯通筛包、均衡失败、同步裁窗、重采样和 compact 截断，并绑定本地文件来源 | `STOP_NO_VERIFIABLE_LOCAL_PAIRING`，后续信息安全及相关性不评估 |
| G2 TX 判别安全 | G1 通过后，另行提交并放行精确的源域载荷与评价计划，按预定 TX、RX 和类别对条件检验安全 | `STOP_TX_INFORMATION_SAFETY_UNVERIFIED` |
| G3 跨 RX 相关性 | G1/G2 通过后，在另行登记的源域分析中证明真实视图差异与判别失效有跨 RX 相关证据 | `STOP_CROSS_RX_RELEVANCE_UNVERIFIED` |

同 TX/RX/Day、相同 shape、相同包数、相同数组下标不能使 G1 通过。公共代码证明某种生成路径存在，也不等于本地 Kaggle 拷贝已经遵循该路径并有完整身份链。

G2 不能由“标签没变”、波形重建质量或一个只在 Raw 训练的分类器在 EQ 上的表现独立证明。后者还混有输入分布适配问题。均衡器也不能被解释为纯粹去除 RX 硬件：它依赖从观测信号估计的信道、同步和噪声过程，可能同时影响 TX 判别信息。这里不以理论可逆或代码结构代替实证判别安全。

全局 GO 需要 G0–G3 都有实际可核对证据。元信息合格不等于训练 GO；若 G1 失败，G2/G3 必须标 `NOT_ASSESSED`，不能说“已证明 EQ 不安全”。从合法原始采集重放处理在原则上可能重建映射，但不属于当前有界元信息任务，不自动启动。

C 的 24 次拟合独立进行。M0 结束后根据冻结出口决定最多一个候选；任何新双视图 CE、一致性或判别保护训练均需独立预注册。当前不能宣称新的算法、物理因果或 WiSig CRD 突破。
