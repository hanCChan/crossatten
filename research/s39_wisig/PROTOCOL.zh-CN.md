# S39 物理监督资格与等预算 A1 对照

S36 在原 STOP 下结题。本轮以 A1 为性能参照，沿用 ManyRx C 的历史源域 V0/V1 和 D1/D2。本轮不访问外层目标 RX、新日期、ManySig 或 LoRa IQ。S40 保留给独立确认；本轮通过也只属于开发证据。

## A Raw/EQ 身份资格

对本地 ManyRx 进行受限 Pickle metadata 索引，禁止数值全量反序列化与逐行猜测配对。把读取字节与数值数组区段做交叉核对，核验顶层和各源白名单数组 schema、同组包数、可追溯身份字段；同时核对官方按采集分组取原始档案的入口。只有同一检测包的原始位置、可信不可变 ID、或官方保存的保留索引可作准入。原始连续采集若只能整批取得，登记可行性和规模；本轮不对包含保留 RX/日期的包作科学解码。

## B 物理匹配

冻结 W4/W5 A1 的两个共同种子。先在原 checkpoint_val 用真实同 TX×RX×Day 中错/对各≥8包的单元求四项严重度的正负变化，各单元以组内中位数差计，接收机等权。四项为秩一残差、非线性相位、重复相干性损失、固定源 TX×Day 的谱形距离，采用 S34 已封存实现。分别扫描白噪声和去线性随机游走相位。每种类型固定 .04/.08/.12/.16/.24 的逐包相对 IQ L2 候选；为避免重复探测，既不混合也不扩展网格。记录全部 source-checkpoint-val 变化及误差。每种只选一次，按四项相对误差的平均绝对值最小选剂量（平局低剂量）。选定值随后在原历史留出视图一次读出。进入训练须两视图在平均剂量下四项均复制真实方向、幅度均在 0.5–1.5 倍内，同时新错误的按真实 TX 条件化的错误标签分布 TV ≤.40，且比同 TX 的均匀错误标签基线减少 ≥.10。每视图至少 5 个真实 TX 有≥20 天然错且≥20 新错。没有候选达标则关闭本轮人工损伤方向。门规定用于证据准入，不作真实失真因果判定。

## C 已有 A1 因子

校验 W4/W5、对应预测和两步更新资产，核对 A0/A1 同包、角色与优化预算。比较真实辅助 TX 方案与 A0，既有 A1 正向若在两视图各≥1 pp 且至少三个配对种子×视图为正（共四对，seed0/1），即认定真实辅助数据复合方案的效应已复制。若没有等训练曝光及计算的原任务对照，训练预算归因仍未识别。

## D 唯一新训练

优先顺序为真正可追溯的配对资格、通过完整签名的人工损伤、C 的训练计算归因。前两条只有 G0 或相关指标改善均不足以训练。若没有前两条达标且 C 资格通过，唯一执行 Target-Extra：用同一原任务 fit_train 做等预算预训练，再走 W4/W5 原下游配方。每视图两个种子。每次首阶段恰好 40×108=4,320 步，batch192、20,736 次包访问/轮，各合法训练包每轮入列一次、余下预算同池无放回补足；只改变额外阶段观察的数据与监督。固定源端验证同预算 6,912 包，固定 source-only EMA BN 复校；Adam、EMA、CE、Plateau 与既有 A1 一致。首阶段 10 类对比 A1 的 72 类，其头被丢弃；数据、标签空间、组内采样与验证域的差异属于整套监督对照，不用于孤立 TX 数的效应。随后按同一 seed 初始化下游头，完整迁移所选 EMA 骨干和 BN，复用 C 的下游环 40×127=5,080 步，所有训练、验证和下游样本顺序与 A1 一致。

最多 8 次拟合、37,600 步。所有选模只在训练 RX。新权重先封存，再读历史留出。报告 Target-Extra−A0、A1−Target-Extra 及同包区间和 RX 安全性。若 Target-Extra 相对 A1 全体≥1 pp、两视图正、条件区间下界>0、最差配对 RX≥−1 pp、Macro-F1 不降，才可提名独立确认。若 A1 明确优于对照，可说明现有辅助监督方案的收益超出这一等预算原任务对照，仍需进一步拆分辅助 TX、RX 与采样。B 的冻结诊断不使用 D 的新模型。
