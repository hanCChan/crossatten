# 阶段 B 正式预注册：替换两个特定源 RX 集合

2026-11-11，Asia/Shanghai；基于 `7ff8986`。这是阶段 A 之后独立登记的四次拟合，首次拟合前提交并推送本协议、输入/代码登记及实现。历史 A、审计、STOP 和数据均保持原样。

## 问题和有限解释

固定 Core、样本预算、TX/day 支持、共同验证集及配对随机流后，替换两个预先指定的 Extension6，是否使 HStem+普通 MHA 对相同 source-held 输入产生可重复的判别变化？B 测量整个训练集合替换在共同自适应策略下的有限效应；不是单 RX 硬件效应，不是 RX 总体平均效应，不是评价环境方差，更不能与 A 的绝对性能相减排名初始化和组成的重要性。

这两个 extension 是按字典序规则划分的具体设备集合。编号与硬件批次、位置或采集条件的关联尚未核实；本实验不作此类物理解释。局部 Jacobian/鲁棒裕量仅为待验证框架，没有可信环境变化族及半径前不启动对应 Loss。

严格复现 `research/training_instance_attribution/CONTROL_PANEL_PLAN.json` 的原规则及全部索引 SHA256：共同 Core6 为 `13-14、13-7、14-7、18-19、18-2、23-3`；composition0 的 extension 为 `23-5、23-6、23-7、24-13、24-16、24-5`；composition1 为 `24-6、7-14、7-7、8-14、8-7、8-8`。每臂 12 RX，8149 个相同 core train 包位于相同规范位置，extension 各 7700 包，总 train 15849 包；共同 core validation 3551 包。

正式登记提交后、首次拟合前，`panel-check` 仅载入登记标签/索引验证两臂原索引摘要，将 `PANEL_PREFLIGHT.json` 提交后才允许训练。该预检不载入 IQ、不加载模型或前向，不计作拟合；其实际元数据访问另记于日志。

依据原 train/val 身份，extension 的每 TX/day 数量取两臂可用数量最小值，按 `SHA256('source-panel-v1|'+repr((rx,day,cell_SHA,ordinal)))` 排序截取。不能用另一种字符串键重算排序后冒充原面板。训练索引 int64、验证索引 int32；原始 dtype 字节摘要必须逐一通过。规范评价键仍采用 A 的 RX/day/cell_SHA/ordinal，不把不同 RX 的同位置当相同输入。

两臂 TX/day 标签序列逐位置一致；每轮使用同流相同 CUDA 相对置换，保存相对位置、实际 pool IDs、实际样本键、TX/day 序列及 core 键序列摘要。匹配只要求相同 slot 的 TX/day，**不**要求两臂 extension IQ 相同。共同 epoch 的相对顺序、标签序列和 core 顺序必须相同；全样本覆盖和共同验证成员必须相同。任一控制失败即停止评价和因素解释。

## 预定分析与实际尺度

validation 和 held 分别完整呈现 selected/epoch10。每运行保留逐包 raw logits、真实类、预测类、最难负类、margin、规范键；报告 RX 等权 Accuracy、固定十类 Macro-F1（缺失类记零）、CE，以及全部 RX、TX×RX、TX×RX×Day 支持、错误、最差组和 margin 1/5/25/50/75/95/99 百分位。评价仅在共同输入上配对。

方向固定为 composition1 − composition0。对 S00/S11 分别给出配对指标差、预测分歧、纠错/新增/双方均错而改类、逐 RX 及全部局部组差异。平均替换对比为 `(ΔS00+ΔS11)/2`；同时给出两流差 `ΔS11−ΔS00`，只描述选定的两套流，不称总体交互估计或总体可重复性保证。没有从 A/B 输出估计全方差分解。

配对 RX cluster bootstrap 10000次、seed22402、percentile95%，所有4模型共享相同 RX 重采样索引；不重采样包充当 RX，也不将两套流当充分 seed 样本。区间仅描述6个固定已观察 held RX 的条件重采样。先对每 RX 的两流差取平均再重采样，并完整给出两流方向是否一致、逐 RX 正负数和具体差值。

总体工程尺度沿用 A：Accuracy/Macro-F1 绝对差0.01、CE0.05nat、同输入分歧0.05。均是预定实用筛查线，不是统计显著性或功效证明。只有两流方向一致、两流及平均都跨相应尺度、平均条件区间不含零，才标记“该指标的有限替换效应有一致支持”；否则保留混合/不确定结论。预测分歧达到尺度本身不能证明准确率或局部风险改善。

局部 TX×RX 风险（错误率）的重复变化预定为：共同支持每流每臂≥50包，两流同方向且各绝对变化≥0.05。完整列出全部组（包括未跨线、反向、零及不足支持），统计满足组数和支持；此为多组探索性筛查，不对单组给总体显著性。TX×RX×day 全表报告，不增加另一套事后门槛。两流一致性不能证明来源于某一物理 RX 参数。
