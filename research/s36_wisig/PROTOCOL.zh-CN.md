# S36 早期 TX 读出、A1 复验与冻结融合

沿用 C ManyRx D1/D2、原 V0/V1 和两个配对种子。主对象为同包 W4/W5 A1 选中 EMA 权重，S29 HStem 为历史机制参照，S29 Long-Patch 只参与 S33 的固定共错定义。使用 S33 和 S34 封存预测校验包身份和历史读数。A1、HStem 的全部主干、BN 与原分类头冻结。没有主干训练、时移/CFO/噪声增强、质量门控、新日期或外层目标 RX 访问，也不触发 S37/S38。

## A/B 正确性转移与可恢复空间

对 HStem 和 A1，分别比较同维 ridge 的原始 Token 均值与第一层 Mixer 后均值，并比较原始 Token ridge 与冻结分类头。逐包分两对、浅层对深层错、浅层错深层对、两错。报告 RX 等权全包率、子集率、Oracle、自然重复相干损失的 fit_train 四分位、RX×TX×Day 聚集、浅层预测的类间第一到第二得分差以及对另一个预定 seed 的复现比例。标准化 margin 除以逐包 10 个分数的标准差。HStem 的浅对深错包报告同 seed A1 判对比例。共错只作历史定义的诊断，不作训练权重或挑包。

## C 冻结融合

原头 logits 为深层主路。新增一个 64→10（650 参数）ridge 头，真实浅路用原始 HStem Token 均值，容量对照用原最终池化向量，负对照在每个角色内按 RX×Day 随机逐包重配浅向量而不使用标签（种子 36061 加视图号）。各路只按 fit_train 估计，固定 1e−4/1e−2/1e−1 相对正则沿用 S34，checkpoint_val RX 等权 Accuracy 选正则，平局较大正则。每路原始 logits 逐包中心化并用 checkpoint_val 上的总体 RMS 标定，再从正比例 {.5,1,2,4,8,16,32} 按 RX 等权 CE 选温度。融合为深路加 α 倍新路，α 从 {0,.125,.25,.5,1} 按同一验证 CE 选择，平局取较小 α。所有读数在留出用冻结选择值一次计算。各方案只新增一头及标量，负对照按同样预算。

主要晋级对象为 A1 的浅融，相对 A1 原头需全体 +1 pp、两视图均正、RX 条件 95% 区间下界>0、最差配对 RX≥−1 pp、RX 等权 Macro-F1 不降、全体平均胜过同容量深层双头与乱序融合，新增参数≤5%。HStem 的融合与 A1 同包比较只作机制参照。条件区间先平均固定种子，再在各视图内重抽 RX 10,000 次，seed24501。报告 +0.5 pp 开发收益与 Oracle 余量，但不替代晋级门。原始测试之后不追加 α、温度、模型或读出。

## D 实际 Mixer

实际 PlainMHA 为位置/输入映射、独立 pre-LN、QKV、注意力加权和输出投影、残差求和、块后 LayerNorm。无 FFN。抽取原始 Token、位置映射后、输入归一后、Q/K/V、注意力投影、归一前残差、第一层输出、最终池化共 10 个均值或向量，统一到 64 维样本 L2 归一。除相同 ridge 外，所有位置各用同样的 64→8→10 GELU 窄 MLP（610 学习参数），20 epoch，batch256，Adam lr=.003、wd=.001，fit_train 更新、验证按 RX 等权 CE 选 epoch（平局早者）。同架构各 tap 初态和样本顺序相同，A1/HStem 同视图/seed 使用同一探针随机流。固定模型状态不参与计算图。另用原模型做三种无重训干预：第一层注意力仅自位置 V、去掉注意力分支但保留块归一、跳过第一层块后 LayerNorm。保持第二层和原头，作为分布外敏感性读数，不能替代受控训练的模块因果结论。

## E 重复块的可迁移 TX 信息

沿用 S34-B 的六块 [20,140)、秩一共享和残差、等宽 120 维归一化谱幅。对原段/共享/残差使用相同源域 ridge 和原型，补测共享＋残差拼接后用固定随机正交投影到 120（种子 36120），报告共享与残差的同包 TX Oracle。另在相同训练 RX 内按 TX 奇偶互换训练和验证 RX 读出，以评估 RX 可读性；跨 RX 读 Day，用两类平衡准确率。辅助读出保持相同固定相对 ridge 强度 .01。对 Raw/EQ 引用 M0 的同包身份门，本轮无新增配对映射。无噪声增强、分支训练或天然失真惩罚。
