# WiSig 下一步研究方案：从射频镜像失真出发，寻找真正的跨 RX 判别机制

我建议把下一阶段定为 M1：复数镜像耦合与 TX 指纹可辨识性研究。

这一次不再尝试新的卷积核、EMA 系数或者通用 Loss，而是先回答一个物理问题：

> 发射机的 I/Q 非理想性会在频谱中产生共轭镜像关系。能否利用这种关系，提取比现有 HStem 更容易跨接收机保持稳定的 TX 判别信息？

这是一个值得验证的研究假设，不是已经证明可行的方法。

我核对了仓库中的 S09、S17、S19、S20 和最新 F2 结果，也查阅了相关射频文献。一个重要事实是：I/Q 不平衡及共轭镜像早已是成熟研究方向，真正的创新不能只是写出镜像公式或增加复数卷积。&#x20;

[image](https://www.google.com/s2/favicons?domain=https://doi.org\&sz=32)

A Survey+2



这一轮的目标应当是：找到新的、能通过物理分析和受控实验共同支持的判别机制，最终在 WiSig ManyRx 正式 CRD 上突破现有强基线。

## 一、先明确为什么选这个方向

历史研究给了我们三个有用的约束。

| 已有实验       | 得到的证据                | 对新方案的要求        |
| ---------- | -------------------- | -------------- |
| S09 相对相位   | ManySig 上相位信息有明确增益   | 继续重视复数信息，不只看幅度 |
| P2 纯时域     | 训练 RX 内很高，留出 RX 明显崩溃 | 保留已验证的频域表示     |
| F2 细／宽频域残差 | F2−F1 仅 +0.024 pp    | 不再依赖普通多尺度卷积增量  |

新的思路需要在这些约束下寻找尚未明确建模的射频关系。

现有 P0 的输入包括频谱实部、虚部、对数幅度，以及相邻频点的相对相位信息。

它已经能学习局部频率关系，但没有专门把正负镜像频率作为一个具有硬件意义的结构进行建模。

要研究的不是频谱相邻关系，而是共轭镜像关系

\\[ Y(f)=aX(f)+bX^\*(-f) \\]

图中的镜像只是解释 I/Q 不平衡会出现的共轭关系。实际 Wi-Fi 前导码本身也有正负频率成分，因此不能把测得的镜像能量全部归为硬件失真。

这里最关键的挑战是：接收机自己也可能存在 I/Q 不平衡。

所以我们不能简单提取镜像强度，再认为它代表 TX 指纹。

必须先研究哪些镜像特征是 TX 相关的，哪些主要随着 RX 变化。

## 二、第一步：建立正确的 TX–信道–RX 物理模型

这是整个新方案最重要的一步。

不能从

\\[ Y(f)=aX(f)+bX^\*(-f) \\]

直接推导出“\\(b\\) 就是发射机指纹”。

因为实际信号经历了多重变换。

### 1. 发射机产生非理想信号

设理想 Wi-Fi 前导码为 \\(s[n]\\)，发射机存在 I/Q 幅相不平衡：

\\[ \boxed{ s_t[n]=\mu_t s[n]+\nu_t s^\*[n]+d_t[n] } \\]

其中：

- \\(\mu_t\\)：正常复信号分量系数。
- \\(\nu_t\\)：TX 共轭镜像分量系数。
- \\(d_t\\)：模型未覆盖的其他 TX 非理想性。

我们希望从接收到的信号中识别与 TX 有关的稳定差异。

### 2. 信道与接收机继续改变信号

信道后的信号可以表示为：

\\[ v[n]=e^{j(\Delta\omega n+\phi)} \big(h\_{r,d}\*s_t\big)[n] \\]

接收机自身也有 I/Q 不平衡：

\\[ \boxed{ y[n]=\mu_r v[n]+\nu_r v^\*[n]+w[n] } \\]

还有一个很重要的数学限制。

如果忽略信道和 CFO，使用增广复数表示：

\\[ \begin{bmatrix}y\\\y^\*\end{bmatrix} = M_rM_t \begin{bmatrix}s\\\s^\*\end{bmatrix} \\]

即使我们能够准确估计乘积 \\(M_rM_t\\)，也不能在没有额外约束的情况下，唯一分离 \\(M_r\\) 与 \\(M_t\\)。

因为对适当的可逆矩阵 \\(Q\\)，有：

\\[ M_rM_t=(M_rQ)(Q^{-1}M_t) \\]

这意味着：只有接收信号、没有接收机校准或额外参考信息时，TX/RX 硬件参数可能在数学上不可唯一辨识。

这不是工程实现的问题，而是模型本身的可辨识性问题。

现有联合 TX/RX I/Q 校准研究往往需要已知训练序列、额外观测或利用 CFO 带来的相位变化。

[image](https://www.google.com/s2/favicons?domain=https://opus.lib.uts.edu.au\&sz=32)

opus.lib.uts.edu.au+1



所以我们这次不能设定一个不切实际的目标——“直接从 WiSig 256 点中恢复真实 TX I/Q 不平衡系数”。

更合理的目标是：研究接收信号中的共轭耦合特征，是否包含跨 RX 可迁移的 TX 判别信息。

这在理论上可证伪，在实验上也能实现。

## 三、M1 的三个阶段与具体出口

M1-A：物理估计是否可信？

确认 WiSig 已知前导码、同步与共轭模型的数值可辨识性，不训练分类网络。

M1-B：这些特征能跨 RX 区分 TX 吗？

用低维特征、传统统计方法及严格留 RX 验证，排除只是识别接收机的可能。

M1-C：设计结构并公平验证

只有 A/B 通过，才开展复数镜像耦合 HStem 的受控训练。

### 阶段 A：物理可行性验证

目标是判断能否从单个 WiSig 前导码中，稳定估计某种有效共轭镜像特征。

WiSig 官方确实提供前导码的前 256 个采样点，但我们必须核实本地数据的采样率、实际截取位置、预处理链路和已知前导码模板，不能仅靠 lag=20 的高相关性假设所有包都已经正确同步。

[image](https://www.google.com/s2/favicons?domain=https://cores.ee.ucla.edu\&sz=32)

CORES Lab - UCLA



具体研究三个量。

A1. 共轭分量的数值可辨识性

给定可信的前导码模板 \\(s\\)，先研究简化模型：

\\[ y\approx as+bs^\* \\]

构造：

\\[ U= \begin{bmatrix} s[0]&s^\*[0]\\\ \vdots&\vdots\\\ s[N-1]&s^\*[N-1] \end{bmatrix} \\]

通过最小二乘获得有效参数：

\\[ \boxed{ \hat{\theta} = (U^HU)^{-1}U^Hy } \\]

实际实现使用 QR 或 SVD，不直接求逆。

这里必须同时检查 \\(U\\) 的条件数。如果 \\(s\\) 与 \\(s^\*\\) 几乎线性相关，那么即使回归残差很小，\\(\hat b\\) 也可能极不可靠。

A2. 正常模型与共轭模型的比较

分别计算：

\\[ E\_{\mathrm L} = \min_a\\|y-as\\|\_2^2 \\]

\\[ E\_{\mathrm{WL}} = \min\_{a,b}\\|y-as-bs^\*\\|\_2^2 \\]

其中 WL 代表 Widely Linear，即广义线性复数模型。

定义相对残差改善：

\\[ \Delta E= \frac{E\_{\mathrm L}-E\_{\mathrm{WL}}} {E\_{\mathrm L}+\epsilon} \\]

需要注意：因为 WL 多一个自由参数，训练残差通常不会更大。所以必须用包内未参与拟合的重复片段进行残差验证，并使用同自由度的非镜像负对照。

否则只是证明参数更多时拟合更好，没有物理意义。

A3. CFO、同步与信道敏感性

真实接收链路不能简单用一个共同的 \\(e^{j\omega n}\\) 乘在 \\(as+bs^\*\\) 外面精确表示，因为 RX 共轭分支会改变相位旋转方向。

因此要采用前面完整的双分支模型做合成测试，覆盖：

- TX-only I/Q 不平衡；
- RX-only I/Q 不平衡；
- 同时存在 TX/RX 不平衡；
- CFO、定时偏移、多径和噪声。

特别需要检查：在 TX 不平衡为零、仅存在 RX 失真的情况下，估计器是否仍然输出明显的所谓 TX 镜像特征。

如果会，那么它可能仍然是一个有效观测描述子，但不能被命名为 TX 硬件参数估计值。

阶段 A 建议预注册出口

| 检查项       | 建议 GO 条件                                |
| --------- | --------------------------------------- |
| 模板匹配与数值条件 | 源数据总体可估计比例 ≥90%，每个有支持 RX×Day ≥80%       |
| 合成参数恢复    | 在预定失真范围内误差满足事前登记的噪声相关容差                 |
| 共轭项独立作用   | 包内验证残差优于同自由度负对照，跨 RX 的方向一致              |
| 数据真实性     | 不通过删除困难包、调起点或查看 source_selection 来改善通过率 |

这些是我建议的候选门槛，不是已有实验结果。参数恢复容差必须先根据仿真噪声范围固定，不能看完源数据后再制定。

如果 A 失败：直接停止这条“显式估计共轭系数”的路线，不进入训练。

这不否定原始复数镜像关系可能有价值，但不允许把不可靠的估计器作为网络输入。

### 阶段 B：证明镜像特征携带跨 RX 的 TX 判别信息

这是决定是否值得训练新网络的核心环节。

A 阶段只能说明某个复数模型可以拟合信号。B 阶段才回答它是否有助于 RFFI。

这里必须避免重复 S17 D0。 S17 已做过中心化 IQ 伪协方差、幅度和相位 RX 描述子的分析，最终没有发现满足门槛的稳定错误关联。

这次必须有两个实质区别：利用可信的前导码模型检查共轭镜像的\*额外\*作用，并直接验证它能否对未参与训练的 RX 提供 TX 判别信息，而不是再计算 RX profile 和错误率相关性。

#### B1：建立少量可解释的描述子

如果 A 阶段的有效广义线性系数可以可靠估计，可构造：

\\[ q=\frac{\hat b}{\hat a+\epsilon} \\]

\\[ \mathrm{IRR}\_{\mathrm{proxy}} =20\log\_{10} \frac{|\hat a|+\epsilon}{|\hat b|+\epsilon} \\]

并保留：

\\[ z\_{\mathrm{mirror}} = \left[ |q|, \Re q, \Im q, \Delta E, E\_{\mathrm{WL}}/\\|y\\|^2 \right] \\]

这里的 \\(q\\) 和 IRR 都必须标注为有效观测代理量，不是已经分离出的真实 TX 参数。全局相位、CFO 与对齐方式也可能影响它们。

对于不可靠的估计，应保留失效标志并报告失效比例，而不是直接删包，让问题较大的 RX 从统计中消失。

#### B2：分析 TX 与 RX 信息是否分离

按 TX、RX、Day 构建平衡统计。可以使用如下描述性模型：

\\[ z\_{t,r,d} = \mu+\alpha_t+\beta_r+\gamma_d +(\alpha\beta)\_{t,r}+\epsilon \\]

其中 \\(\alpha_t\\) 描述 TX 关联变化，\\(\beta_r\\) 描述 RX 关联变化。

这个模型不是物理因果分解；尤其是 RX、位置、信道条件和采集环境可能混杂。

但它能回答：

- 同一个 TX 换不同 RX 后，特征分布是否仍然有共同结构？
- 不同 TX 的差异是否大于对应的 RX 内波动？
- TX×RX 交互是否强到使特征无法可靠迁移？

建议报告各因素的解释量、跨 RX 的 TX 类中心关系，以及 Day1/Day2 的重复性，而不是只画几张 PCA 图。

#### B3：做一个非常简单的分类实验

先不训练深度网络。

用固定的低维特征，进行跨 RX 的 10 类 TX 识别：

| 对照 | 输入           | 用途              |
| -- | ------------ | --------------- |
| T0 | 原有幅度、相位等低维统计 | 检查普通特征的能力       |
| T1 | 共轭镜像描述子      | 检查镜像信息本身        |
| T2 | T0 + 共轭镜像描述子 | 检查是否存在额外信息      |
| N0 | 事前固定的非镜像负对照  | 排除一般特征维度和拟合能力收益 |

只使用预先固定的标准化与正则化线性分类器。若需要调正则化强度，必须在 fit RX 内进一步分组，不能用 source_selection 选择。

真正要观察的是：

\\[ \boxed{ \Delta\_{\mathrm{mirror}} = \operatorname{Acc}\_{\mathrm{heldRX}}(T2) - \operatorname{Acc}\_{\mathrm{heldRX}}(T0) } \\]

也可以把镜像描述子加到冻结 P0 embedding 的线性探针中，检验是否提供现有表示尚未充分利用的信息，但这一探针只能作为事前登记的辅助实验，不能事后替代主比较。

建议的 B 阶段晋级条件：

- T2 相对 T0 在合法内部留 RX 上平均至少 +2 pp，接收机聚类条件区间下界大于零。
- 两个源域开发视图方向一致，不能只在一个 RX 上大幅改善。
- 镜像负对照不能获得类似的增量；各 RX×Day 的可靠性和失效数量完整披露。
- 不出现少数有充分样本支持的 TX×RX 组大幅恶化而平均收益掩盖问题。

其中 +2 pp 是建议的探索性实用门槛，可以在看到数据前调整并冻结；不是统计学定理。还要报告单独的 T1，即使 T2 通过，也不能据此证明改善完全由 TX 硬件指纹引起。

如果 B 没有明确的跨 RX 增量，就停止镜像机制，不进入网络训练。

## 四、只有 A/B 通过，才设计真正的新网络

如果前两阶段验证成功，我不建议再采用 F2 那种“冻结原网络、加 3,201 参数侧路”的结构。

F2 已经证明，在这一配置下新增特征很难被固定分类器有效利用。新物理特征若存在，需要允许分类器重新学习其判别关系。

建议候选模型为：

Mirror-Aware HStem：共轭镜像耦合的层级射频特征提取。

### 1. 输入保持原五通道频域骨干

仍然保留原 P0：

\\[ V(X)= [\Re X,\Im X,\log|X|,\Re P,\Im P] \\]

这里 \\(P\\) 是现有的相邻频点相对相位通道。

不改变原 RMS、FFT、相位有效性掩码和 HStem token 坐标。

### 2. 增加物理结构约束的镜像耦合

对每一个频点 \\(k\\)，构造：

\\[ \boxed{ u_k= \begin{bmatrix} X[k]\\\ X^\*[(-k)\bmod N] \end{bmatrix} } \\]

它和普通卷积的区别是，直接让正负镜像频率发生复数交互。

候选变换可以表示为：

\\[ \begin{bmatrix} h_k\\\h_k^\* \end{bmatrix} \approx \begin{bmatrix} a\_\theta&b\_\theta\\\ b\_\theta^\*&a\_\theta^\* \end{bmatrix} \begin{bmatrix} X[k]\\\X^\*[(-k)\bmod N] \end{bmatrix} \\]

这里是示意性的广义线性算子。实际网络必须明确输出如何投影回原频域 HStem，不应把同一个 \\(h_k\\) 和 \\(h_k^\*\\) 当作两个任意独立输出。

可以先采用低秩或分组参数，在所有镜像频点之间共享主要系数，再通过轻量卷积学习频率相关变化。

这一结构必须以保留原有信息的方式加入。 不能强制抵消镜像，因为它可能包含 TX 指纹。

### 3. 让 HStem 和 Attention 端到端训练

原始 IQ → 原五通道 FFT

原 HStem 分支

保留强频域基线

镜像耦合分支

X(f) 与 X\*(-f)

轻量融合 → 32-token → MHA → TX 分类

这次最值得验证的不是新模块让训练 Accuracy 增加多少，而是：

\\[ \boxed{ \text{正确镜像配对} \quad\overset{?}{>} \quad \text{普通额外复数特征} } \\]

所以必须有严格的物理特异性对照。

## 五、新结构阶段的训练设计

只有 A/B 通过并独立完成预注册后，我建议使用以下三臂。

| 实验臂 | 方法                            | 目的           |
| --- | ----------------------------- | ------------ |
| R0  | 原频域 HStem+MHA，采用统一 EMA 配方     | 强标准参照        |
| R1  | 同参数额外复数交互，但使用预先固定的非镜像频点配对     | 排除容量与额外交互的影响 |
| R2  | 正确的 \\(f\\) / \\(-f\\) 共轭镜像配对 | 唯一新机制候选      |

这里有个重要区别：R1 不是随机生成一个坏模型，而是采用与 R2 同结构、同参数量和同训练预算的非物理配对对照。

如果 R2 比 R0 好，却不能超过 R1，那么可能只是额外容量有效，无法支持镜像关系的独立价值。

## 18 次

18 次为未来候选预算，不是当前授权。如果六个现有 R0/EMA 模型与新协议完全一致且能通过封存身份复核，可以研究严格复用；不能为节省训练而混用不匹配的模型。

训练规则建议直接采用已验证的 C 阶段强配方，并在开始前冻结：

- 全部实验臂共同使用相同的训练 RX、分割、随机流和可比更新预算。
- R0/R1/R2 均端到端训练，使用相同的 EMA 和 fit-only BN 策略。
- 模型选择仅在合法 fit RX 的 checkpoint_val 上进行。
- 采用普通 CE，不增加 GRL、SupCon、GroupDRO 或新的 Margin Loss。
- 按 RX 聚类计算 Accuracy 差异，同时报告 Macro-F1、CE、最差 RX 与所有有支持的 TX×RX 风险。

### R2 的准入条件

建议相对 R0 和 R1 同时满足：

| 指标                | 建议要求        |
| ----------------- | ----------- |
| RX 等权 Accuracy    | 均至少 +1 pp   |
| 配对 RX 条件区间        | 下界大于 0      |
| 两源域视图             | 均改善         |
| 随机流               | 至少 2/3 改善   |
| 最差配对 RX           | 不低于 −2 pp   |
| 最大受支持 TX×RX 错误率增加 | 不超过 5 pp    |
| 参数量与推断延迟          | 不超过预注册的工程预算 |

这里的 1 pp 是晋级门槛，不是正式 CRD 预期收益。所有区间仍只条件于已观察的源 RX，不代表独立新 RX 总体的置信保证。

通过这些门槛，才值得推进 ManySig 迁移与正式评估；否则停止。

| 最终确认 | 需要另行确定合格的独立协议                                           | target8、Day3–4 和 UNKNOWN RX 继续关闭 |

尤其要强调：本轮前两个阶段不能通过逐包匹配不同 RX 的波形来估计 TX 硬件参数。

现有 WiSig RX 可能接收同一批发射事件，但跨接收机的包序是否严格对应仍没有完成证明。可以分析 TX×RX×Day 分组统计，不能凭数组位置直接配对。

另外，你已经反复使用了同一批开发 RX。后续即使 R2 获得显著提升，仍只能称为复用开发协议下的结果。新的独立确认需要另行解决数据资格问题。

## 七、如果镜像路线失败，怎么办？

我不建议把它继续延伸为十几种网络结构。

这条路线只有两个值得保留的出口。

情况一：有效镜像系数本身无法稳定估计。

那么停止显式 I/Q 参数估计，不继续尝试“校准 RX”。

此时可以将未来研究转向不依赖单个硬件参数可辨识性的复数统计表示，但必须重新提出独立假设，不能自动把 R2 当作替代方案继续训练。

情况二：镜像特征可以可靠估计，但无法跨 RX 区分 TX。

说明镜像特征可能主要反映接收链路或其他混杂因素，不值得投入神经网络训练。

这时更有价值的是回到 ASKNet 与 HStem 的复频谱处理差异，考虑能够完整保持能量或复数几何关系的表示，而不是继续堆加镜像通道。

目前已有研究讨论了 I/Q 不平衡、接收机校准与 RFFI 的关系，因而即使 R2 成功，还必须证明为什么已有广义线性处理、复值网络或普通镜像输入不足以达到相同效果。
