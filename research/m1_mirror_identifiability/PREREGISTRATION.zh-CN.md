# M1-A 固定协议：0 分类器，0 深度训练

用户授权仅覆盖 M1-A；不承接已结束的 F2 训练许可。分支基于 `81ec476`。P2、F2、固定周期窗口、S09/S17/S19 全部原 STOP 不变。S17 D0 已研究中心化伪协方差/RX profile；本轮不重复其错误相关性研究，而检验已知参考的额外共轭投影能否预测包内未拟合片段。

## 先登记后访问

注册阶段只读公开文本、历史协议和来源 sidecar；没有 IQ、模型、embedding、预测数组访问。`REGISTRATION.json` 固定代码、文档、来源 SHA 和白名单，须提交后才能运行。合成工程检查通过后才能解码源 IQ。无自动失败重试或替代估计器。实现错误可在源访问前修复并重新提交工程版本，全部失败记录保留；源访问后不改变科学算法。

## 模板、拟合与同阶控制

- 25 Msps、256 点未均衡 Id signal，保留现有功率归一化缓存，不做均衡或重采样。来源核查见 SOURCES.md；本地 Kaggle 拷贝的归属来自既有 manifest，不宣称已与当前 UCLA 下载逐字节比对。
- 仅固定 [20,180) 候选内部区间。fit=[20,100)，validation=[100,180)，各四个短重复周期。源范围不是已证实的绝对 STF 起点；边界或模板不匹配会失败，不移动窗口。
- 先用 fit 段 RMS 确定统一标度。CFO 仅由 fit 内 lag20 的复相关相位估计；周期相位仅在 fit 内以固定 0:0.25:19.75 点网格选择。不得读取 validation 选 CFO/相位/参考。此预定逐包相位估计不是看过结果后调整截窗。
- L：单列 s；WL：两列 s,s*；NC：两列 s,c。c 是同十二个占用频点、同谱幅度、同周期的非镜像参考，按已登记符号向量循环移位一位；不使用带外噪声列制造弱对照。三臂各自使用相同相位网格搜索、同一 CFO 估计，阶数对照 WL/NC 均为两复参数。
- QR/SVD（`lstsq` / SVD pinv），rcond=1e-12。精确残差等价分支（≤1e-12×fit能量）按最大直接系数幅度、再最早相位固定规范；报告半周期结构歧义。不命名为真实 TX 参数或真正的 I/Q IRR。
- 有效条件：输入有限、非零能量；各设计满秩、condition≤10；abs(CFO)≤200kHz；WL fit/validation NMSE 都≤0.15；abs(a)≥0.1、abs(b/a)≤0.5。后两项限定直接分量占优的有效观测范围，不是硬件已校准的证据。

## 合成范围与事前容差

seed=27101，complex128。nu_t∈{0,0.08 exp(j0.4)}、nu_r∈{0,0.06 exp(-j0.7)}；CFO∈{-100000,0,100000} Hz；时间相位∈{0,0.5,3} 样本；channel 为 [(0,1)] 或 [(0,1),(2,0.2 exp(j0.8))]；SNR∈{10,20,30} dB；每格8次，共1728包。初相0.3。所有格含失败均报告。

已知时序、零 CFO、平坦已知信道的有效系数恢复容差为 `6*sqrt(2)*sigma/sigma_min(U_fit)`（无噪声另用1e-10）；这是噪声方差和固定设计给出的容差，不使用源数据校准。合成全链路可估计比例≥90%。额外必须通过：完整前向等式、RX-only不等于TX归因、四列的可辨识/秩亏报告、十点平移歧义、信道列空间反例、错模板/边界/零能量/秩亏拒绝、validation 不影响拟合参数、数据权限先于 IO。所有工程断言通过才开放源 IQ。真实 TX 参数恢复不作为可实现承诺。

## 受限源抽样

仅 C 源域两个视图共同 fit 的六台 RX，原 train_ids，Day1–2。它们与两视图 source_selection 并集不相交，避免在一个视图中是训练、另一个视图中是留出时误读。每个非空 RX×TX×Day cell 按 SHA256(`M1-A-v1|pool_row`) 排序固定取最多16包；少于8包则支持门失败；空 cell 明列，不补包。不跨 RX 对齐或配对事件。

白名单仅 fit_x、fit_y、fit_rx、fit_day、train_ids。四个元数据数组只用于边界、抽样、分组；共享源池中非授权行不进入科学汇总。fit_x 允许整文件字节摘要核验与只读 mmap，仅将选中的 common-fit_train 行复制/解码为科学输入。checkpoint_val、source_selection、历史 held6、target8、D3–4、UNKNOWN RX、任何模型和预测均关闭。

独立复核可重读完全相同的登记行，用另一份频率多项式和 QR 求解器回放已选相位的系数与留片残差；不新增唯一IQ行，也不据此选择方法。

## 固定源出口

1. 全部抽样包有效比例≥90%；每个有支持 RX×Day≥80%；各非空cell至少8包，六台RX两日均存在。不删失败或困难组。
2. 逐包验证优势 A=(E_NC−E_WL)/max(E_L,1e-12)，采用同一 validation 能量归一化。无效包记0优势但保留原残差/原因。先每 RX 平均，再六 RX 等权：优势≥0.02；六台 RX 方向均>0、两日方向均>0；对六个已观察 RX 的条件 bootstrap 下界>0（10000次，seed27102）。同时 L−WL 的相对验证改善的 RX 等权均值>0。
3. 完整报告 TX×RX×Day、失败原因、CFO、模板相位、channel proxy 与可靠性关联（Spearman仅描述）；不做 TX 分类或因果分解。复杂 q 仅供诊断，不导出为已准入的网络输入。

任一门失败则 `STOP_EXPLICIT_MIRROR_ESTIMATOR`，不改阈值、起点、对照或范围。不进入 B/C；通过仅为 `M1_A_PASSED_B_REQUIRES_SEPARATE_AUTHORIZATION`，不证明跨 RX TX 判别信息存在。M1-B/C 的分类器、正则化、架构及18次未来预算在本轮均不执行。
