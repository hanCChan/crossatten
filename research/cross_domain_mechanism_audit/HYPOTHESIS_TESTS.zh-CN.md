# 下一阶段最小证伪设计

这是待预注册的研究设计，**不是已登记、已运行或已通过的实验**。本次没有新增正式拟合、源 IQ/预测读取或 target 访问。不要把下列设计当成已获实证准入的 S21。

## 共同起点：G0 数据与推断权限

先列清使用单包、包集合还是校准信号。保留当前 S19/S20 的单包推断时，不得悄悄引入测试 RX 统计、测试 TX 标签或多包自适应。需要这些信息的候选可以研究，但必须另列协议，并让基线拥有同样信息。

只检查既有文档/元数据即可先回答：

- 是否有可证明的同包跨 RX 映射、准确时间戳或共同校准激励？若没有，禁止用数组相同下标做物理配对；仍可声明为未配对的条件总体统计分析。
- TX–RX–day 支持是否足以估计所用模型？二部图连通不足以证明任意高阶交互可估计；不得填补不存在的 cell 后当成实测。
- 同一 TX 的位置、激励、采集时段与 RX 条件是否混杂？哪些环境因素有独立测量，哪些只是代理？
- 哪些 RX/日期/seed 结果已经看过？已查看的 held-source 组属于探索资料，不再作为对新假设的独立确认。

**出口：** 缺少单包物理识别条件时，降低结论至可预测的统计变化，或明确提出新的校准采集。不能用一个归一化层代替缺失测量。当前元数据准备性没有被本轮认定为全部通过。

## A：存在可迁移而不过度损伤 TX 的低维接收环境分量

**具体主张：** 在指定前端和扰动范围内，用部分 TX/日期估计的低维环境效应，可以预测其他 TX/日期的环境变化；对该分量的受约束处理能保持 TX 判别裕量。主张必须限制到可验证的族，不能写“分离全部 RX 失真”。

**最小分析：**

1. 在合法 fit-source 训练部分定义谱特征、可辨识模型、支持权重及频率/倒谱基。比较“TX 主效应 + RX/day 主效应”与包含 TX×RX 交互的替代解释。处理 `log1p`、谱零点与功率依赖；不能直接假定加性。
2. 以完全留出的 TX 子集和日期单元做预测检验；报告预测误差、相对无 RX 项/随机置换项的改善、交互残差及区间。使用共同支持或显式缺失设计，不能靠改变 TX 组成生成伪 RX 效应。
3. 检查被处理子空间与 TX 差异的重合，并在冻结分类器上测 TX margin、每 TX 错误和最差组变化。散度保留和 probe 都只是诊断，需功能性证据。使用等秩随机子空间、无操作、同失真强度对照。

**证伪：** 留 TX/日期预测不优于对照；所需 TX×RX 交互与共同 RX 项同量级且无法受限；或者处理稳定牺牲关键 TX。此时停止“共享平滑 RX 响应”的方法化，不能通过提高平滑阶数追逐准入。

**与 S17 的区别要求：** S17 已测跨 TX/日期稳定性；重复同类均值相关不是新贡献。新分析必须事先说明新增可识别条件或定量的跨 TX 预测，并解释 S17 未稳定通过的 fold。若无新增可检验内容，直接复用旧证据并判为重复。

## B：源统计约束的生成变化对应真实环境变化

**具体主张：** 一个从 fit-source 独立估计、事先限制的 `A(f) exp(i phi(f))` 族，能逼近未参与估计的源环境差异，且对 TX 有功能性保护。

**最小分析：**

1. 先固定变化族、参数估计、功率/因果性/边界实现、适用信噪比，以及是否包含广义线性或非线性项。不能因为形式是滤波器就称为真实 RX。
2. 用未参与估计的 TX/day/source 条件比较真实变化与生成变化，分别报告覆盖、方向特异性和失配；使用同 EVM 噪声、全局相位及匹配复杂度的随机 FIR 对照。EVM 相同不代表信息影响相同。
3. 在冻结模型上检验 TX 保护与真实源风险的功能变化。标签在软件中未改不等于指纹信息未损伤。禁止只用另一个可受同样混杂影响的 TX probe 作证。

**证伪：** 只能保持 TX 却不能对应真实变化，或扩大覆盖后损伤 TX；结论均不支持增强训练。S17B 已给出前一种反例，应先说明本次变化族如何避免该失败，不能直接加大预算。

合成“已知滤波器 + 精确逆滤波器”恢复只验证实现，不证明真实 RX 可恢复。若未配对数据只能支持总体对应性，应明确这一证据等级。

## C：一个明确的物理作用需要结构约束

**具体主张：** 对明确定义、标签安全且在数据中相关的作用 `g`，结构使 `Phi(gx)=rho(g)Phi(x)`，并保留 TX 所需信息。

**最小分析：**

1. 先给出作用、群/局部集合、组合规律、有限窗口边界和可逆范围。例如全局相位与 CFO 是不同作用；循环时间移位和截断后的实际包偏移也不同。
2. 证明或构造检查 TX 轨道不发生相关碰撞；对于近似不变性，声明允许的裕量损失。不能仅以“发射机实体未换”认定变换不损伤观察到的 TX 线索。
3. 用合成输入逐层检验等变残差、梯度和边界，再比较普通复数层/实数层/受约束层，在同配方和匹配预算下检验独立收益。SincNet、LEAF、scattering 是不同先验，不能同时加入后把收益归给等变性。

**证伪：** 只有在不相关的作用下满足代数关系；对相关变换会合并身份；或约束后的收益被普通层加相同增强/预算解释。此时不把结构名称作为机制结论。

## G4：进入算法比较前要固定的项目

只有单一假设通过机制检验后，才安排一项最小算法与必要控制。参照应覆盖冻结 HStem+MHA、官方 ASKNet 整体配方，以及同一 backbone 的强 ERM；根据所声称的最坏组或平坦性机制，选择一个对应训练控制。官方配方比较与同配方因果比较分开报告。

预注册至少应包含：

- 所有 fit/validation/exploratory/confirmation/target 的 RX、日期和实际包索引角色；曾看过哪些结果；共同支持与缺失类规则。
- 候选数、调参次数、seed、最大拟合数、训练时长、选模指标、early stop、异常修复流程及失败出口。
- 一个主要收益指标及实际有意义的最小效应；平均 RX 风险、最差配对 RX/TX 风险及不确定性均需报告。根据最小效应和历史方差确定预算，不能在本审计中临时虚构样本量充分性。
- 按唯一 RX 处理重复身份；共享训练集、多 seed、日期相关性和多重候选带来的区间限制。单次最差 RX 与总体最坏风险不是同一估计对象。
- 无操作、匹配扰动/容量/算力对照；所有模型先封存，再一次性读取新的确认结果。沿用既有盲测边界，不因本次审查打开 target。

对已知 S20 最差 RX 的后续定向分析可以作为探索，但不能用同 RX 上的修复幅度充当独立泛化证据。若剩余未查看的合法 source 确认资源不足，应诚实报告无法独立确认，并设计新的采集或下一份协议，不能把包重抽样或改 seed 当成新的独立 RX。
