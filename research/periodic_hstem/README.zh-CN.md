# WiSig 周期坐标 HStem：先核验信号，再决定结构实验

本工作承接用户提供的“为什么 LoRa 上 HStem 能明显提升，WiSig 却一直突破不了？”研究建议。问题是：周期坐标下的局部波形与跨周期变化，能否提供比当前频域 token 更合适的归纳偏置？本阶段不以 EMA、GroupDRO 或新 Loss 补救结构假设。

## 第一步：有界可行性核验

在任何本阶段 IQ 数值检查之前，提交 `AUDIT_REGISTRATION.json`、核验代码及合成测试。只从 C 阶段两视图**共同 fit RX** 的原 `train_ids` 中，按 RX×TX×day 确定性抽取至多 16 包；不读取 checkpoint_val/source_selection 的 IQ，不读取 historical held6、target8 或日期3–4。源数组白名单和 SHA 从已完成的 C 阶段登记继承，保留原文件与历史记录。

WiSig 论文记载采样率为25 Msps，L-STF短周期0.8 μs对应20点，完整L-STF为200点。原代码的前160点并不是整个L-STF的物理长度。非均衡包由能量检测截取，不能假设256点全部属于L-STF，也不能从周期自相关单独识别绝对短符号边界。

- [WiSig原论文 §III–IV](https://arxiv.org/html/2112.15363)：采样率、能量检测、256点截取及均衡流程。
- [MathWorks L-STF](https://www.mathworks.com/help/wlan/ref/wlanlstf.html)：20 MHz L-STF为10个0.8 μs短周期。
- 历史 S07 的 lag=20相位通道是已有对照；本假设的区别在二维分层提取，不把相同相位差重命名为创新。

固定候选周期20，固定主要窗口 `[20,140)`（6周期，零基、右开）。检查20种窗口起点 `[20+d,140+d)`、d=0…19，防止一次高相关掩盖局部非重复区间；不以检查结果选择更好的窗口。逐包计算最差相邻周期归一化复相关，以及lag20相对lag19/21的区分度。复相关取模允许真实CFO存在，不执行CFO补偿、均衡或分量删除。

**预设工程可行性门**：逐包在全部20种起点下，最差相邻周期相关≥0.7且lag20对lag19/21优势≥0.05；至少90%包通过、每RX×day至少80%通过；每实际存在的RX×TX×day至少8包。缺失组合如实列出，不填零。门槛只判断这一个固定窗口能否支持普遍使用的周期排列，不是TX分类效果或显著性检验。所有包均计入分母，不筛除低相关包后再报通过率。零能量、非有限值包计失败。

同时报告lag1…80谱、固定区域及滑窗相关，作为解释性结果，不用于选择新周期/新窗口或修改门槛。周期门通过也只支持“包相对坐标下相邻行约为重复波形”，不证明跨包列具有相同绝对符号相位，更不证明TX/RX信息已分离。

**停止规则**：未通过则停止这一固定周期排列的训练，不改窗口、不放宽阈值、不追加样本或种子；保留失败证据。只有通过后，才另行提交独立的三结构训练预注册及合成验收，不把可行性结果直接写成识别率提升。

## 第二步：条件式最小三结构实验

若第一步通过：当前频域HStem+MHA、普通一维时域HStem、周期二维HStem，共用源包、现有分类器接口及两源视图，3个配对随机流，不加Loss或训练因素网格。时域与二维对照须控制有效参数、输入信息及窗口；保留整包信息，避免把裁剪收益误认为二维结构收益。训练配方、参数容差、共同初始化与独立样本顺序、checkpoint_val选型、全部模型封存后才一次评分source_selection，以及RX等权Accuracy/CE、最差RX、TX×RX风险门，在训练前独立冻结。

第一轮只决定是否值得继续；即使有源域收益，也不能称正式CRD突破。后续要单独与包括EMA完整配方在内的强参照比较，并按资格明确的协议验证。现有新RX资格未定，不冒称新盲测。
