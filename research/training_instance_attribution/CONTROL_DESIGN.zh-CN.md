# 分开实施的稳定性归因控制设计

本文件是**实验设计草案，未训练、未做新 IQ 访问、未获实证准入**。不把方案中列出的拟合数当作已经授权或完成的预算。阶段 A、B、C 分别登记和解释，不能一次同时改变随机性、RX 组成和损失。

## 先确定能回答的问题

只读历史审计不能给出初始化、顺序或源 RX 对错误的因果贡献比例。下一项受控实验先回答：**在同一训练数据和同一选模策略下，改变初始化或批顺序，HStem+MHA 的已知 TX 判别会有多敏感？** 不先回答“哪一个新方法改善泛化”。

固定科学范围为历史 fold2 的合法 source：现有 fit18 和日期1–2；source-held6 仅作探索性评价。该折 target8 不准用于训练、选模或评价。RX3-19/TX4 已看过，只作预先列明的案例；同时报告全部 held RX/TX/day，不能以该案例改善作为新泛化成功。

## A：固定数据，分开改变初始化与批顺序

建议最小工程/归因区块为 **2×2 因子设计 + 1 次相同设置重放，共5次拟合**，只用 HStem+普通 MHA 与原 CE。它是少量固定 seed 水平的有限对比，不是可靠总体方差分解或功效充分的算法确认。

| 运行 | initialization seed | order seed | model stochastic seed | 数据、split、主干、损失 |
|---|---:|---:|---:|---|
| A00 | 22101 | 22201 | 22301 | 全部固定 |
| A00-replay | 22101 | 22201 | 22301 | 与 A00 完全相同 |
| A10 | 22102 | 22201 | 22301 | 仅初始化因子改变 |
| A01 | 22101 | 22202 | 22301 | 仅批顺序因子改变 |
| A11 | 22102 | 22202 | 22301 | 用于估计所选水平的交互对比 |

seed 必须真正分流：先用 initialization seed 构建/保存初始 state；模型内部 RNG 在加载 state 后重置到固定 stochastic seed；顺序使用独立 generator。**不要继续用包含 fold 的一个 data_seed 同时控制一切。** 初始 buffers/BN 状态、train/val 索引与顺序也必须保存，而不是只声明 seed 相同。

当前 HStem+普通MHA 路径没有启用 Dropout，M0 也没有输入增强；因此第三个 stochastic seed 是固定的工程防护记录，不是本次新增因子，不能为实验再加入 Dropout。BN 随批序改变的状态属于批顺序效应。ASK 训练中的 Gumbel 截止是另一显式随机源，HStem 的2×2实验不能直接代替 ASK 的归因控制。

保留历史 HStem 训练策略作为该区块的共同规则：Adam1e-3、wd0、batch128、FP32、最大40轮、RX等权验证CE选模、plateau(.1,5,min1e-6)、earlywait10，无输入增强。`augmentation_probability=.5` 在原 M0 中未实际启用，不能误当成新的增强随机源。

保持**策略**相同不意味着实际 LR、停止轮数、checkpoint epoch 相同。它们可能是初始化/顺序影响的中介。主要解释是“在固定自适应训练策略下的总敏感性”。额外保存所有运行的固定 epoch10 snapshot（早停最早在 epoch11），作为不受最佳 epoch 选择影响的预定辅助端点；主/辅助结果不能事后择优。若研究目标改成排除 LR/停止中介的直接效应，应另登记固定轨迹实验，不能把本区块冒充这种实验。

必须先检查 A00 与 replay 的初始权重、每轮规范样本键顺序、训练状态与预测是否重现。如果 GPU 算子不能 bitwise 重现，应记录最大数值差及分类差异，停止“仅 seed 因子已充分隔离”的解释；不能放宽到任意 accuracy 容差后宣称控制成功。重放也是一次拟合，不能计成0成本。

固定 data_seed 不等于固定初始权重：需要相同 initialization 水平的跨 order 运行具备相同初始 state 哈希。相同 order 水平需产生相同逐轮样本键序列。记录 optimizer/scheduler/RNG 状态与 BN buffers，保存 selected 和 epoch10 snapshot；没有这些证据不进入因素归因。

## B：固定随机性，改变合法源 RX 组成

仅在 A 完成并登记其解释后执行 B。**不能把历史 folds1–3 的训练 RX 并集26直接用于固定 fold2**：其中 `19-1、19-2、19-19、19-20、20-1、20-19、20-20、23-1` 是 fold2 target；即使它们曾在别的 fold 合法作 source，也不能跨角色借入。

本轮已经只用旧标签/索引生成了可复现的[面板设计](CONTROL_PANEL_PLAN.json)：

- 固定 fold2 fit18 内按字典序前6台作为共同 core；其余12台分成两个6台 extension。每臂均12台训练 RX。
- core 的 **8149** 个旧 train 包完全相同且处于相同规范位置；仅替换 extension。
- 每个 TX/day 的 extension 数量取两臂可用数量的较小值，用固定 SHA256 排序确定保留行；每臂 extension **7700** 包、总 train **15849** 包。不补造缺失 cell，不对困难包按结果选择。
- 两臂 train 的 TX/day 标签序列逐位置相同，数据总量和每轮 batch 数相同。相同 order generator 可对两臂施加同一个相对置换；core 样本位置相同，extension slot 的 TX/day 相同。
- 选模只使用共同 core 的同一 **3551** 个旧 validation 包。不能一臂用已见验证RX，另一臂用被移除RX来改变选模信息。
- source-held6 在两臂共同封存后一次性探索性读取；该折 target8 不打开。

建议至少用 A00、A11 对应的两套预定随机流做两臂配对，共 **4 次新的拟合**。其训练集与验证集不同于 A，A 的模型不能严格复用为 B 的基线；旧 S17B/S20 模型也不满足这些面板条件。相同自适应策略下 LR/停止可作为组成变化的中介，需连同结果报告。

这是 RX 组成的**整体替换对比**，不能从两臂结果推断某一单独 RX 的因果作用，也不能推广到任意接收机总体。若要研究单 RX 增删，须另登记等样本/等更新对照，避免将训练量增加误判为覆盖改善。

## C：之后才决定是否加入既有组风险控制

待 A/B 表明需要什么控制后，再登记强 ERM 与一个既有 TX×RX 风险目标；不同时改变骨干、输入、随机性分流、数据和评价权限。此时才固定具体算法、超参数、拟合数、功效/工程最小收益与失败出口。

只有 train/val/input、初始状态、随机流、训练/选模规则及代码都满足新注册时，才可复用 A 或 B 的对应 ERM；不提前把历史模型算成匹配基线。组风险目标属于既有控制，不预设论文创新，也不因某个历史坏组被修复就宣布泛化成立。
