# S30 WiSig 冻结模型物理扰动审计

复用 S29-R 八份选定权重和原始角色。ManyRx fold2、D1/D2 两个历史源域留出视图，冻结权重与既有预测按哈希校验。零梯度更新。外层目标 RX、ManySig、新日期和 Shen IQ 都不读取。S31 在本轮没有拟合预算。

## A 同包剂量响应

- CFO 取 0、±1、±2、±2.5、±5、±10、±15、±20 kHz。每个 CFO 比较包首锚定、包中心锚定和与锚点变换同相位的恒定旋转。设 q=n−127.5，包首旋转 exp(jωn) 精确分解为 exp(jωq) exp(jω127.5)。比较三种同包干预，模型准确率的变化无需加性。
- 时移取 ±1、±2、±4、±8、±9、±16 点。使用 S29 的等保留样本 aligned/shifted 对，另做原始/循环移位和原始/裁损参照。联合扰动比较 ±2、±5、±10 kHz 中心锚定 CFO 与 ±4、±9 点，联合损失以同一个 aligned 支持为基准，符号等权。另核对已知 CFO 逆旋转和匹配时移逆移位。
- 先按 RX 等权，保留每符号、每 RX/TX、每 seed 的 Accuracy、Macro-F1、CE、最小 RX 表现。HStem 少掉分为正。主读数是 0–5 kHz 中心锚定 CFO 和 0–9 样点等支持时移的单位剂量 AUC，使用梯形积分并除以剂量跨度。全范围和单剂量曲线是诊断。各 RX 内先平均种子，视图分层重抽已观察 RX 10,000 次，seed 24501。两项主读数分别报告未校正条件区间。额外列出均值、两视图方向和最差配对 RX。

## B 首个可观察到稳定性差异的位置

在 ±5/±10 kHz 中心锚定 CFO 及 ±4/±9 点等支持时移，比较共享的 Tokenizer 输出、后端最终池化和 logit 三个位置。Token 响应计算全位置相对 L2，其他位置以各自维度计算，logit 先逐包去均值。另报告以参考整体 RMS 归一的响应，检查每包分母主导的情况。TX 分离度在各 RX 内算类等权类间/类内离差比。序列表征先沿 token/位置求均值，各类最少 20 包，每个 RX 至少 2 类。并读正确类相对最强错误类的 margin 变化。HStem 各中间卷积块单独探索。不同网络学习了不同表征坐标，读数定位差异首次出现的位置，无法直接识别某一层的中介因果贡献。

## C 自然 CFO 的统计归因

仅用 S29 审计数组中的训练包和原可靠掩码。按包 ID 去重，V0/V1 重叠成员不作为独立样本。每个支持至少 8 个可靠包的 TX×RX×Day 单元取 CFO 中位数，单元等权。比较只含 TX/Day 的模型、增加 RX 主效应的模型，以及各自加入 TX×RX 或 RX×Day 的模型。只在所有模型均可识别的共同留单元集上比较预测 MAE，另报主效应的更广共同留单元集。两日期×两 TX 半组（编码奇偶）交叉验证 RX 相关残差复现性，以同 TX 同日的其他 RX 中位数为参照，要求每半组每 RX×Day 至少 2 个 TX、每个参照至少 3 台其他 RX。未知 RX 的个体效应需要它自己的独立校准观测，这个统计练习不将 RX 系数解释成已知硬件本振。

## 推进判定

若 0–5 kHz 中心锚定 CFO AUC 差达到 1 pp，条件区间下界 >0，两视图方向一致，并且跨 TX/日期 RX 尺度可复现，再将微幅 CFO 增强列为有源域证据的候选。RX 复现要求 RX 主效应的留单元 MAE 比 TX/Day 基线低至少 15%，两个奇偶 TX 跨日方向均至少有 6 台 RX，Pearson r ≥0.6，预测 MAE 均低于零预测。单一包首锚定大剂量优势不会代替此判定。时移单列，原包窗口标签有效性和样点丢失与追加平移不同。当前方案不启动任何一致性损失、新结构或正式 CRD。
