而且这一结论在历史已使用 confirm 上保持一致：HStem 对 MHA 提升 +2.823 pp，对 RF-HSTU 提升 +2.131 pp。

这说明分层特征提取并不必须依赖 HSTU 才有效。

\\[ \Delta\_{\rm interaction} = \Delta\_{\rm HStem|HSTU} - \Delta\_{\rm HStem|MHA} = -0.542\ \mathrm{pp} \\]

这不是“层级结构与 HSTU 具有正向协同”的证据，反而提示 HStem 对普通 MHA 的帮助可能更大。

但是还有一个重要的归因限制：目前 Patch Stem 与 HStem 的参数量、感受野、降采样路径并不相同。 因此现有实验能够证明这两种 Stem 实现 的性能差异，却尚不能唯一证明收益来自“层级结构本身”，而非容量、感受野或卷积计算量。

这就是接下来最值得解决的核心问题。

增益单位为百分点（pp），两个数据集使用各自B0基线。

三个发现非常清楚。

第一，直接随机增加 CFO 并没有改善现有 WiSig 模型的整体泛化，两个数据集都退化。

第二，把所有可靠包校正到估计频偏为零，同样导致整体准确率下降。这符合此前的担忧：观测频偏可能携带 TX 身份相关的信息，不能直接视为纯 RX 干扰。

第三，原始+校正双路在 ManySig 上确实出现了值得记录的探索性信号：相对 B0 为 +2.740 pp，相对参数完全相同的双原始支路为 +3.625 pp，后者 4/4 folds 为正。

但 ManyRx 只有 +0.328 pp，相对双原始控制也只有 +0.327 pp、2/4 folds 为正，最差 RX 配对变化约 −4 pp。

所以 `STOP_SOURCE_GATE` 是合理的。它表示当前方法不满足预先规定的稳健部署标准，并不意味着“校正后频谱永远没有价值”。

S14 又对这 40 个模型完成了分组诊断：6,720 条分组记录、5,376 条配对记录，并核查了 21 个异常 CFO cell；没有删除样本，也没有使用诊断结果重新挑选模型。它仍然无法提供天然 CFO 真值，因此不能把性能变化直接归因于接收机本振误差。

来源：[S13 CFO 完整报告](https://github.com/hanCChan/crossatten/blob/exp/s13-mixer-cfo/13-mixer-cfo-mechanisms/P2_CFO_RESULTS.md?utm_source=chatgpt.com)、[S14 CFO 机制诊断](https://github.com/hanCChan/crossatten/blob/exp/s14-stem-mixer/14-stem-mixer-attribution/CFO_MECHANISM_REPORT.md?utm_source=chatgpt.com)。

## 四、S14 还暴露出一个重要的效率取舍

我读取了 S14 的 `costs.csv` 和真实模型实现：

| 指标         | Patch+MHA | HStem+MHA |
| ---------- | --------- | --------- |
| 参数量        | 571,434   | 133,690   |
| 计数 FLOPs   | 138.68M   | 190.06M   |
| Dev RX 准确率 | 95.222%   | 97.335%   |

HStem 将参数量减少约 76.6%，与此同时，把计数 FLOPs 增加约 37.1%。

从代码看，这是因为 Patch Stem 使用一个较宽的 `Conv1d(32,64,kernel_size=256,stride=256)` 进行 Token 化，而 HStem 用多层小卷积逐级降采样、在中间进行归一化和非线性变换。

它没有证明哪一种计算更经济，但证明了一个非常有意思的现象：

直接使用一个大卷积生成 Token，虽然操作路径比较简单，却需要大量卷积核参数；分层小卷积可能更有利于学习可泛化的 RF 局部结构。

这也是接下来可以发展成论文核心贡献的方向。

但需要加上限制：这种优势目前是 HStem 与当前 Patch 实现之间 的优势，而不是已经对所有轻量 Stem、所有层级结构都成立。

## 七、S16：真正值得投入的新主线——源接收机物理失真建模

如果目标是让第二篇不仅有 LoRa 结构贡献，还能在 WiSig 的跨 RX/Day 场景中形成新的算法贡献，我更建议研究这一方向，而不是继续修改 CFO 校正器。

### 1. 为什么换这个方向？

目前 P0 已经提示，深层仍然保留 RX 信息；S12 的简单频谱约束不稳定；S13 的 CFO 增强和校正也没有通过门槛。

这些结果共同说明一个可能性：

接收机差异并不是一个单独的频偏标量可以描述的，而可能是多种随频率变化的幅度、相位和时序失真共同作用。

可用下面的简化信号模型帮助理解：

\\[ Y\_{t,r,d}(f) = X_t(f)H\_{r,d}(f)+N(f) \\]

这里 \\(X_t(f)\\) 包含发射机身份相关信息，\\(H\_{r,d}(f)\\) 则代表与接收设备、日期及传播环境有关的综合响应。

这只是研究假设，不意味着现有数据能唯一估计接收机硬件的真实传递函数。特别是 RX 与信道效应并不一定可分。

### 2. 先做零训练机制诊断

先利用 WiSig 合法源 RX 的数据，对每个 TX/RX/day 单元构造频域统计，分解可观察的：

\\[ D\_{\rm TX},\qquad D\_{\rm RX|TX},\qquad D\_{\rm Day|TX,RX} \\]

观察频率响应、局部相位差及特征层的接收机差异，分别与跨 RX 错误关联。

我建议先检验三个假设：

| 假设                       | 具体诊断                | 意义           |
| ------------------------ | ------------------- | ------------ |
| H1：RX 差异主要表现为平滑幅度响应变化    | TX 条件化频谱幅度差异及其频率相关性 | 是否适合幅度响应随机化  |
| H2：RX/Day 差异具有低阶相位或群时延特征 | 对齐检查后分析相位斜率与时序偏移    | 是否适合物理相位扰动   |
| H3：某些发射机特征在这些扰动下仍可保留     | 比较 TX 类间散度和留出 RX 错误 | 是否存在可利用的不变部分 |

这里要特别注意：诊断时可用源 TX 真值控制混杂，但部署模型不能依赖目标 TX 标签。

如果这些假设没有得到支持，就应该停止物理响应增强路线，而不是继续堆模型。

### 3. 有诊断支持后，再尝试受约束的物理扰动增强

一个可验证的候选方向是：

\\[ \widetilde X(f) = X(f)\cdot A\_{\theta}(f) \cdot e^{j\phi\_{\theta}(f)} \\]

其中 \\(A\_{\theta}(f)\\) 是平滑幅度响应扰动，\\(\phi\_{\theta}(f)\\) 是受约束的相位响应扰动，扰动的范围和相关长度通过源 RX 数据估计。

它不同于 S13 那种简单的整体 CFO 旋转，也不同于 S12 直接截断特定频带。其目的是模拟接收链路中可能的多频率响应变化，并测试这种建模能否让分类器减少依赖接收机特征。

建议 Pilot 对照如下：

| 实验臂 | 处理         | 目的       |
| --- | ---------- | -------- |
| W0  | 原有最强合法源域基线 | 统一比较对象   |
| W1  | 仅平滑幅度响应扰动  | 检验接收幅度偏差 |
| W2  | 仅低阶相位/时延扰动 | 检验相位偏差   |
| W3  | 联合响应扰动     | 检验组合收益   |

这四种方法不应同时修改分类头、输入通道和训练目标。先固定 S08 的主干与训练协议，另以公平训练的 ASKNet 作为强基线，防止把配方差异误认为新方法优势。

## 八、浅层适配还要不要做？

我建议暂时放到独立分支。

原因是它回答的部署问题不同：

| 路线                        | 是否使用新 RX 无标签数据 | 论文定位                        |
| ------------------------- | -------------- | --------------------------- |
| 当前 S15/S16                | 否              | 严格零样本 Domain Generalization |
| 浅层 Adapter / BN / 全模型 TTA | 是              | 低成本无监督接收机适配                 |

已有 Tent 和 CSCNet 等工作覆盖熵最小化、归一化更新和部分网络适配的基础思路，不能仅因“只更新第一层”就宣称新颖。

## 十、最终优先级：现在最应该做什么？

第一优先级：S15 参数匹配 Stem 消融

补齐 HStem 创新归因最明显的缺口，成本可控，并且已有较稳定的正向证据。

第二优先级：S16 WiSig 物理差异诊断

先搞清 ManyRx 的接收机失真和日期漂移到底影响哪些特征，再决定是否训练新结构。

第三优先级：物理约束的源域扰动建模

只有诊断支持时，才进入新的受控 Pilot 和独立确认。

现阶段我对第二篇的判断是：

LoRa 部分已经有相当完整的实验基础，可以支撑“分层 RF Token 表征具有更高参数效率及更好的跨 RX 识别精度”这个有边界的结论。 但它还不够证明一个具有普遍性的新型跨接收机泛化算法。

WiSig 部分则需要真正的新方法。 已完成的 S11–S14 实验说明，简单频带筛选、频谱稳定性先验、CFO 随机增强与直接校正都无法同时满足 ManyRx 和 ManySig 的稳健性要求。继续堆叠类似模块，很可能只得到更多数据集特定的增益。

因此，下一步最值得转变的是研究方式：从“试一个模块能否涨分”，转向“先测量接收机引起了什么失真，再让模型针对被验证的失真建立鲁棒性”。

这更符合你这篇论文的电磁与信号处理背景，也比单纯替换 Transformer 内部结构更容易形成一条完整、可解释、可检验的科研贡献链。
