## 二、必须补充的实验 1：LoRa 的 Stem × Mixer 联合消融

最高优先级新增实验

这是我认为第二篇论文最值得补、甚至比继续研究 HSTU 内部门控更重要的一项实验。

原因是：HSTU 已经存在于第一篇论文中。第二篇真正新增的是分层 HStem 及其与 RF-HSTU 的组合。因此，仅证明 HSTU 比 CNN-only 好，还不足以证明第二篇新增结构为什么有价值。

### 实验设计

把两个变量拆开：

- Stem：普通 Patch Stem / 分层 HStem
- Mixer：普通 MHA / RF-HSTU

|               | 普通 MHA         | RF-HSTU        |
| ------------- | -------------- | -------------- |
| 普通 Patch Stem | 新增 E1          | 新增 E2          |
| 分层 HStem      | 已在 S13 P1 中：A1 | 已在 S13 P1 中：A3 |

这样可以计算两个重要差值。

分层 HStem 对 MHA 的收益：

\\[ \Delta\_{\rm MHA} =\operatorname{Acc}(\mathrm{HStem+MHA}) -\operatorname{Acc}(\mathrm{Patch+MHA}) \\]

分层 HStem 对 RF-HSTU 的收益：

\\[ \Delta\_{\rm HSTU} =\operatorname{Acc}(\mathrm{HStem+HSTU}) -\operatorname{Acc}(\mathrm{Patch+HSTU}) \\]

如果两者都明显提高，就能证明 HStem 本身具有价值，而不是必须依赖 HSTU。

如果第二个提升明显更大，才可以进一步讨论 HStem 与 HSTU 存在结构上的互补性。应报告交互差值 \\(\Delta\_{\rm HSTU}-\Delta\_{\rm MHA}\\) 及其不确定性，不能仅凭两个均值直接认定存在协同作用。

建议新增训练量：12 个 fit

2 个新实验臂 × 2 folds × 3 seeds。其余两个实验臂复用 S13 已完成且满足完全配对要求的模型。

所有实验保持同一 Shen P-H5x160 数据协议、输入视图、源 CE 选模规则与训练预算。普通 Stem 参数量与 HStem 不同，因此要同时报告参数、FLOPs 和延迟；若想主张“参数更高效”，还要引入合适的参数匹配控制。

### 判断标准

| 结果                      | 应该怎样写论文                    |
| ----------------------- | -------------------------- |
| HStem 对 MHA 和 HSTU 均有收益 | 分层 RF Token 提取是独立有效的贡献     |
| HStem 对 HSTU 收益明显更大     | 可以进一步论证两种结构的互补性            |
| HSTU 与 MHA 精度相近         | 不能说 HSTU 本身明显优越，重点转为 HStem |
| MHA 比 HSTU 更准、更小、更快     | 应主动调整创新主张，而不是继续选择有利实验      |

注意，S13 首批源验证结果中，普通 MHA 已有竞争力，而且 A1 的参数量和单包延迟都比 A3 略小。真正的未见 RX 结果非常关键。

## 三、补充实验 2：RF-HSTU 的真正机制消融

这组实验不要立即启动，而是等完整 P1 得出结果后再决定。

S13 目前的 A3/A4/A5 主要检验：

\\[ \mathrm{Sigmoid}\quad\text{vs}\quad\mathrm{Softmax}\quad\text{vs}\quad\mathrm{SiLU} \\]

但它还没有拆开两个有价值的结构：

\\[ Y=W_o\left(\operatorname{LN}(AV)\odot\operatorname{SiLU}(U)\right) \\]

其中一个是 \\(U\\) 门控，另一个是相对位置偏置 \\(B\_{\rm rel}\\)。

| 新实验 | 改动            | 核心问题                  |
| --- | ------------- | --------------------- |
| G0  | 原 RF-HSTU     | 基线                    |
| G1  | 去除 \\(U\\) 门控 | 收益是否来自特征门控？           |
| G2  | 去除相对位置偏置      | 相邻 RF Token 的位置关系重要吗？ |

新增 G1/G2，沿用同一 2 folds × 3 seeds，预计 12 个 fit。

如果 RF-HSTU 在 P1 的真正未见 RX 上并不优于普通 Attention，这组机制消融应降为次要，没必要为了证明预设结论继续扩大搜索。

## 四、补充实验 3：WiSig 不只看平均涨分，还要解释 CFO 是否真的有效

S13 已经规划了 B0、B1、B2 Corrected、B2 Dual、B2 Dual Raw 五种模型。我建议完整执行这 40 次 Pilot，不必新开一套重复训练。

但是在模型完成后，应补充一组不需要训练新网络的分组诊断，让论文能够解释为什么涨分或为什么失败。

| 补充诊断      | 具体操作                    | 预期能回答的问题           |
| --------- | ----------------------- | ------------------ |
| CFO 误差分组  | 按观测 CFO、校正置信度分组         | 校正对哪些信号有效？         |
| 低置信度分组    | 比较 coherence ≥0.7 与较低分组 | 回退机制是否必要？          |
| RX/day 分组 | 按每个留出 RX 和日期报告变化        | 是普遍改善还是少数 RX 拉高均值？ |
| TX 条件分析   | 比较各 TX 校正前后表现           | 校正是否删除 TX 判别信息？    |
| CFO 扰动曲线  | 同一已训练模型施加冻结的多个 CFO 扰动幅度 | 稳定性是否真的提高？         |

这里有一个优先排查的问题：P0 报告显示 ManyRx 出现少量 TX 条件化后超过 50 kHz 的异常单元。

建议核查这些异常是否与 STF 起点偏移、低可靠性或估计歧义有关。仅用于分析，不允许看完结果后删除异常样本来提高分类准确率。

这一组实验最重要的对照是：

\\[ \mathrm{Dual(raw,corrected)} \quad\text{vs}\quad \mathrm{Dual(raw,raw)} \\]

假如 Dual Corrected 提高 2 pp，而 Dual Raw 也提高 2 pp，那么收益可能只是增加参数造成的。

只有 Dual Corrected 相对参数匹配的 Dual Raw 也稳定获益，才能说明校正后的表示提供了额外信息。

### P2 什么时候可以进入真实 WiSig CRD？

沿用 S13 已冻结的源域联合门槛：

| 条件                         | 晋级要求    |
| -------------------------- | ------- |
| ManyRx 平均增益                | ≥ +1 pp |
| ManyRx 正向 folds            | ≥ 3/4   |
| 两数据集最差 RX 平均变化             | ≥ −2 pp |
| ManySig 平均增益               | ≥ 0 pp  |
| ManySig 达到至少 −1 pp 的 folds | ≥ 3/4   |

通过 Pilot 后，再使用另一留出 RX 分组和独立种子确认。只有通过源域独立确认，才值得冻结最终模型并进行一次正式 CRD 评估。

不能用 WiSig CRD 反向修改 CFO 幅度、融合网络或阈值。

## 五、补充实验 4：真正验证你师弟的浅层适配假设

这是目前还没有做的独立研究，也是我认为下一阶段最有潜力发展成新方法的一项。

P0 只是分析浅层和深层特征，并没有进行“浅层微调和全模型微调”的同口径对照。

要验证你师弟的说法，应设计下面的实验。

| 实验 | 更新参数              | 适配数据      |
| -- | ----------------- | --------- |
| T0 | 完全冻结              | 不适配       |
| T1 | 仅更新 BN 统计         | 新 RX 无标签包 |
| T2 | 仅更新 BN 仿射参数       | 新 RX 无标签包 |
| T3 | 更新第一层卷积或小 Adapter | 新 RX 无标签包 |
| T4 | 更新全模型             | 新 RX 无标签包 |

所有方法必须从同一源域预训练模型开始。

先采用一个已有的统一无监督目标，例如熵最小化，固定学习率选择范围、更新步数和增强策略，避免不同实验使用不同优化器后无法归因。

建议使用如下预算：

| 阶段    | 规模                                     | 目的       |
| ----- | -------------------------------------- | -------- |
| Pilot | 4 源 RX folds × 1 seed × 5 方法 × 1 个适配预算 | 看有无稳定信号  |
| 独立确认  | 新种子、另一留出 RX 分组                         | 验证效果能否复现 |
| 样本效率  | 每个 RX 使用 16、64、256 个无标签包               | 比较不同适配成本 |

这里的关键不是尽量把新 RX 训练到最高准确率，而是研究：

仅改变少量浅层参数，是否能够达到与全模型适配相近的泛化收益，同时降低更新成本与灾难性遗忘？

评测时，每个新 RX 的无标签适配包和有标签评估包必须严格分离。部署时不能使用 TX 真值做频偏中心化或模型更新。

这一方向一定要单独标注为 UDA/TTA，不能与第二篇论文目前严格不访问目标 RX 的零样本 DG 成绩混排。

如果这条路线成立，还能进一步研究一个更有创新潜力的结构：固定深层 TX 判别网络，只在浅层加入接收机条件的低秩或轻量校准模块。不过这应当是实验支持浅层适配后再开展的下一阶段，而不是现在直接投入大量训练。

## 七、做到什么程度才算足够支撑论文？

我建议最终至少形成下面三个能够被独立验证的结论。

贡献一：分层 RF Token 设计。 证明在相同 LoRa 协议下，分层提取相对普通 Stem 具有可复现的跨 RX 优势，并准确交代参数量、FLOPs 和延迟的取舍。

贡献二：Token 交互机制。 不仅证明 HSTU 比无 Mixer 好，还要证明它相对普通 MHA、Transformer 的实际优势或局限。不能因为使用了 HSTU 就自动认定存在新的第二篇论文创新。

贡献三：跨 RX/日期的物理泛化。 如果 WiSig CFO 路线通过独立验证，就将其作为真正新增的方法贡献；如果未通过，诚实保留负结果，不强行包装成解决方案。

还有一点需要特别强调：LoRa 与 WiSig 使用的是不同的输入前端，不能因为两个数据集都用了 HStem-HSTU，就直接说已经证明了一个完全统一、跨不同无线体制的最优模型。

所以，我给你的执行建议是：让当前 S13 按原方案跑完；然后优先新增 12 次 Stem × Mixer 消融，以及不增加训练量的 WiSig CFO 分组诊断。 浅层无监督适配单独开一个研究分支，不要和本篇严格零样本的主实验混在一起。

这样最有利于用有限的实验预算补足创新证据，而不是继续无目的地增加模型复杂度。
